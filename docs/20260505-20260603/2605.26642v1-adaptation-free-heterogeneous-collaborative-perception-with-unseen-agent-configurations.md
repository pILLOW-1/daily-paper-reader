## 摘要
协同感知通过使代理共享互补观测信息来提升3D物体检测性能，但现有方法大多假设固定的或已知的协作者编码器配置，限制了实际部署。本文考虑一种开放世界场景，其中具有未见配置的辅助代理可能在部署后出现，例如不同的LiDAR波束数或编码器架构。为应对这一挑战，我们提出ALF——一个协同感知框架，通过将轻量级边界框级消息提升为自车兼容的辅助特征，实现对未见代理配置的零自适应协作。ALF将辅助边界框级消息转换为伪BEV地图，并通过将物体中心线索与自车特征的场景上下文相结合，合成自车兼容的潜在特征。在V2X-Real数据集上，跨64个案例的零样本评估中，ALF在相对mAP@0.7上比最强先前基线高出35.91%，同时每代理每帧仅需120字节（10 Hz下约9.6 Kbps带宽）。

## Abstract
Collaborative perception improves 3D object detection by enabling agents to share complementary observations, but most existing methods assume fixed or known collaborator encoder configurations, limiting deployment in practice. In this work, we consider an open-world setting in which auxiliary agents with unseen configurations may appear after deployment, such as different LiDAR beam counts or encoder architectures. To address this challenge, we propose ALF, a collaborative perception framework that enables zero-adaptation collaboration with unseen agent configurations by lifting lightweight box-level messages into ego-compatible auxiliary features. ALF converts auxiliary box-level messages into pseudo-BEV maps and synthesizes ego-compatible latent features by combining object-centric cues with scene context from the ego feature. On V2X-Real, under a zero-shot evaluation across 64 case studies, ALF outperforms the strongest prior baseline by 35.91% in relative mAP@0.7 while requiring only 120 bytes per agent per frame (approximately 9.6 Kbps bandwidth at 10 Hz).

- **问题**：协同感知中现有方法通常假设辅助代理的编码器配置（如LiDAR线束数、主干网络、体素化设置）在训练时固定或已知，但实际部署中可能遇到**未见过配置**的辅助代理（open-world setting），导致特征空间不兼容。
- **背景**：中间融合（intermediate fusion）虽权衡了带宽和表示能力，但核心挑战是**表示异构性**：不同配置的辅助代理产生的特征与自车特征空间不一致。现有方法（如基于适应、重建、生成的方法）需要针对每个新配置额外训练适配器，缺乏可扩展性和部署便利性。
- **整体含义**：本文旨在解决**配置无关的异构性**（configuration-agnostic heterogeneity），即无需任何额外适应或微调，即可与训练时未出现过的辅助代理进行有效协作。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **晚到中融合（Late-to-Intermediate Fusion）**：辅助代理只发送轻量级的**框级消息**（box-level message，如3D检测框的坐标、尺寸、朝向、置信度），避免了传输配置相关的潜在特征；自车端利用这些框级消息合成出自车兼容的潜在特征，从而实现中间融合级别的特征交互。
- **关键设计**：框级消息作为通用通信接口，解耦了通信与融合；自车特征提供场景上下文，将稀疏的物体中心线索“提升”为融合就绪的潜在表示。

### 技术细节
1. **框级消息压缩**：每个辅助代理发送最多Kmax个检测框，每个框包含6个字段（中心x, y, 宽度, 长度, 偏航角, 置信度），统一量化到INT8，每个消息仅120字节。
2. **Box-to-BEV Rasterizer (B2BR)**：自车端将接收的框级消息去量化、通过相对位姿变换到自车坐标系，然后在BEV网格上栅格化每个框的足迹（占用区域赋值为该框的最大置信度），生成单通道伪BEV图Xi。
3. **Ego-compatible Feature Synthesizer (EFS)**：
   - **物体中心线索编码器 (OCE)**：用卷积-归一化-SiLU块将伪BEV图编码为紧凑的物体中心特征Oi。
   - **自车上下文注入模块 (EIM)**：采用双阶段金字塔设计，将自车特征F1通过平均池化后添加到不同尺度的Oi上，并通过上采样融合多尺度信息，得到两个自车增强特征Z'(1), Z'(2)。
   - **自车兼容潜在精炼器 (ELR)**：拼接Oi、Z'(1)、Z'(2)，经过投影和三个残差块，输出与自车特征空间对齐的潜在特征Fî。
4. **损失函数**：目标检测损失（focal分类损失 + Smooth L1回归损失）+ 区域加权余弦对齐损失（对物体区域和背景区域分别加权，使合成特征接近自车编码器对辅助观测编码后的教师特征）。
5. **训练与部署**：仅训练EFS参数，冻结自车编码器、融合模块和检测头。训练后EFS固定，部署时无需任何微调，任何辅助代理只需提供框级消息和相对位姿即可参与协作。
