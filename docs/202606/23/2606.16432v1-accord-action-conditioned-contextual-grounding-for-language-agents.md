## 摘要
用户指令常常因人类对周围环境的隐含假设而表述不充分。对于在信息丰富的数字和物理环境中运行的大型语言模型（LLM）代理而言，这些假设无法仅从指令中推断出来；它们必须从工具、数据、界面和观察的当前状态中恢复。因此，有效执行要求代理识别缺失的上下文，将其建立在观察到的证据之上，并将其带入后续行动。我们表明，当前的代理往往未能做到这一点。它们基于假设而非观察到的具体细节行动，忽略本可以收集到的信息，并且未能整合已经返回的证据。基于这一洞察，我们提出了ACCORD（动作条件上下文基础），一种简单有效的自适应基础代理框架。在每次动作之前，ACCORD主动探测环境中缺失的信息，并整合代理轨迹中原本会被忽略的相关上下文。无需额外训练或任务成功信号，ACCORD在AppWorld上将任务目标完成率从GPT-5-mini的42.0%提升至62.6%，相比强基线提高了最多20.6个百分点。这些提升在使用更强的基座模型（Claude-4.5-sonnet提升10.8个百分点）、开放权重模型（Qwen3.5-27B-FP8提升10.1个百分点）以及具身AlfWorld基准测试（GPT-5-mini成功率提升7.4个百分点）时仍然保持。

## Abstract
User instructions are often underspecified because humans rely on implicit assumptions about the surrounding environment. For large language model (LLM) agents operating in information-rich digital and physical environments, these assumptions cannot be inferred from the instruction alone; they must be recovered from the current state of tools, data, interfaces, and observations. Effective execution therefore requires agents to identify missing context, ground it in observed evidence, and carry it forward into subsequent actions. We show that current agents often fail to do so. They act from assumed rather than observed specifics, overlook information they could have gathered, and fail to incorporate evidence that has already been returned. Building on this insight, we propose ACCORD (Action-Conditioned Contextual Grounding), a simple and effective agent framework for adaptive grounding. Before each action, ACCORD actively probes the environment for missing information and integrates relevant context from the agent's trajectory that would otherwise be overlooked. Requiring no additional training or task-success signals, ACCORD improves task-goal completion on AppWorld by up to +20.6 points with GPT-5-mini, from 42.0% to 62.6%, compared to strong baselines. These gains persist with a substantially stronger base model (+10.8 with Claude-4.5-sonnet), an open-weight model (+10.1 with Qwen3.5-27B-FP8), and on the embodied AlfWorld benchmark (+7.4 success rate with GPT-5-mini).

- 现有agent框架将环境主要视为任务执行场所和反馈来源，但很少将环境视为**解决用户模糊意图的信息源**，导致agent在写操作（write action）时缺乏环境 grounding，造成任务失败。
- 论文识别出两种具体的 grounding 失败模式：
  - **Incomplete（信息缺失）**：必要信息从未进入轨迹，agent 未主动探测环境；
  - **Overlooked（信息忽视）**：信息已在轨迹中，但 agent 在写操作时未使用。
- 论文提出 ACCORD 框架，通过在每个会导致状态变更的写操作前主动插桩、重新浮出轨迹证据并探查环境，实现**动作条件的自适应 grounding**，显著提升任务完成率。

## 2. 方法论
### 核心思想
- 在每次环境写操作（POST/PUT/DELETE 等）执行前，由一个独立的 **Grounding Agent** 暂停主代理，接收当前轨迹和任务指令，构建“动作就绪上下文”（action-ready context），使写操作所依赖的论据、约束、实体标识等都能与当前环境状态一致。
- 两层设计：
  - **推理时层（Grounding Agent）**：负责具体 grounding，执行两个互补动作：
    - (A) Re-surface：从已有轨迹中重新浮出被忽视的关键事实（解决 overlooked）；
    - (B) Probe：通过只读API调用探查环境中缺失的信息（解决 incomplete）。
    - 随后决定 APPROVE（批准执行写操作）或 REJECT（阻塞执行，将冲突环境证据追加到历史，让主代理重新提议）。
  - **策略层（Policy-Level Shaping）**：通过轻量级提示修改主代理的系统 prompt，鼓励其早期多探索、检查实际内容而非猜测，从而丰富轨迹，为推理时层提供更充足的环境信息。

### 关键技术细节
- **写操作集的自动构建**：若环境暴露 API 元数据（如 HTTP method），直接标记；否则通过一次轻量 LLM 分类（按 API 签名和自然语言描述）得到，仅需一次，跨任务复用。
- **Grounding Agent 的工作流程**：
  1. 收到主代理的写操作提案 `w`、轨迹 `c_t`、任务指令 `x`；
  2. 检查约束满足、实体歧义、模式对齐等；
  3. 执行只读探测（一个或多个代码块）；
  4. 输出 DECISION: APPROVE 或 REJECT，REJECT 附上冲突证据（仅客观环境信号，不含主观判断）。
- **AlfWorld** 中由于环境信息紧凑，采用简化设计：Grounding Agent 仅编译客观状态报告（当前位置、携带物品、任务词汇、未访问容器等），追加到上下文后让主代理重新采样动作，无 APPROVE/REJECT 决策。

## 6. 主要结论与发现
- ACCORD 在所有设置下一致提升任务完成度，最大增益在 AppWorld challenge 上：GPT-5-mini TGC 提升+20.6（42.0→62.6），Claude-4.5-sonnet 提升+10.8（73.4→84.2），Qwen3.5-27B-FP8 提升+6.7。
- 自校正方法（Self-Refine、FullCodeReflex）反而效果下降，说明仅靠内部推理无法弥补环境信息缺口。
- 消融显示：**动作条件上下文增强是核心**；通用前置探索（PE）单独无用甚至有害，必须结合动作条件；完整 ACCORD 相比 PE+GP 仍有额外收益（+6.0 TGC）。
- ACCORD 增加了读操作比例（70.4%→82.7%），减少了写操作比例，表明每次写更可能成功。
- 失败模式分析：基线失败中 26.7%–36.7% 为 incomplete 型，33.3%–66.7% 为 overlooked 型，验证了这两种 grounding 缺口的主导性。

## 7. 优点
- **训练无关、模型无关**：无需微调或任务成功信号，直接应用于不同 LLM 和环境。
- **针对两种具体失败模式设计**：re-surface 解决 overlooked，probe 解决 incomplete，机制透明。
- **实验覆盖全面**：多模型（闭源/开源/小模型）、多任务类型（API / 具身）、多难度层级，且包含消融和分析。
- **与流行方法对比公平**：ReAct 和 Self-Refine 等均在同一设置下测试，并指出自反响的局限性。
- **开源**：提供项目页面和代码，便于复现。

## 8. 不足与局限
- **依赖 API 分类**：需要预先定义哪些操作是写操作（尽管可通过元数据或轻量 LLM 自动完成），在无元数据的环境中仍需一次性 LLM 调用。
- **额外 Token 成本**：Grounding Agent 引入只读探测和模型推理，增加了每任务的 token 消耗，尽管写操作次数未增加。
- **AlfWorld 中设计不一致**：采用简化版（无 APPROVE/REJECT），可能影响对比的严格性。
- **策略层提示手动设计**：GP 和 PE 的措辞是作者手工编写，可能非最优，存在进一步自动优化的空间。
- **缺乏理论保证**：未对 grounding 成功概率或收敛性提供理论分析。
- **基准局限性**：实验仅在合成基准（AppWorld、ALFWorld）上进行，现实应用（如网页交互、物理机器人）中噪声和不确定性更大，可能影响迁移性。
- **ACE 基线不完全公平**：因上下文长度限制部分任务未完成，论文已标注为“参考点”，但读者需注意。
