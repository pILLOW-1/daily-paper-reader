## 摘要
现有的记忆增强型大语言模型智能体仅在提示空间中存储过往经验，如文本摘要或检索到的段落，同时在整个展开过程中保持模型参数不变。这类智能体可以“查阅”它们之前看到的内容，但无法“从中学习”：其策略不随经验改变，任何从上下文中丢弃的信息都会永久丢失。我们提出\texttt{TMEM}，一种自我进化的参数化记忆框架，其中智能体不仅将历史压缩为显式记忆，还通过轻量级在线更新将蒸馏的监督信息吸收到快速LoRA权重$Δ_t$中，从而在一个回合内真正改变其未来行为。我们将其形式化为具有快速权重展开动态的智能体决策过程：动作从$π_{θ_0+Δ_t}$中采样，而提取动作产生更新$Δ_t$用于后续决策的监督信息。这一视角使得提取策略可以直接通过强化学习进行优化：训练$θ_0$不仅改进了任务动作，还提高了用于在线LoRA适应的数据的质量。我们进一步提出了基于奇异值分解的LoRA子空间初始化，以加速在线收敛。在LoCoMo、LongMemEval-S、多目标搜索和CL-Bench上的实验表明，\texttt{TMEM}在不同模型规模下始终优于基于摘要和基于检索的基线方法。

## Abstract
Existing memory-augmented LLM agents store past experience exclusively in prompt space, as textual summaries or retrieved passages, while keeping model parameters frozen throughout a rollout. Such agents can \emph{look up} what they have seen but cannot \emph{learn from} it: their policy is unchanged by experience, and any information dropped from the context is permanently lost. We introduce \texttt{TMEM}, a self-evolving parametric memory framework in which the agent not only compresses history into explicit memory but also absorbs distilled supervision into fast LoRA weights $Δ_t$ via lightweight online updates, genuinely altering its future behavior within a single episode. We formalize this as an agentic decision process with fast-weight rollout dynamics: actions are sampled from $π_{θ_0+Δ_t}$, while extraction actions produce supervision that updates $Δ_t$ for subsequent decisions. This view makes the extraction policy directly optimizable by RL: training $θ_0$ improves not only task actions but also the quality of the data used for online LoRA adaptation. We further propose SVD-based initialization of the LoRA subspace to accelerate online convergence. Experiments on LoCoMo, LongMemEval-S, multi-objective search, and CL-Bench show that \texttt{TMEM} consistently outperforms summary-based and retrieval-based baselines across different model scales.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有的大语言模型（LLM）智能体在长时间交互（多轮对话、长序列搜索、工具使用等）中，仅将过往经验存储在提示空间（如文本摘要、检索段落），而模型参数在整个回合（episode）内保持冻结。这意味着智能体可以“查阅”历史信息，但无法“从中学习”——策略不随经验改变，任何被丢弃的上下文信息都会永久丢失。这种“看而不学”的机制严重限制了智能体的长程自适应能力。
- **整体目标**：提出一种新型参数化记忆框架，使智能体能在单次回合内将提炼后的经验写入自身模型参数（通过快速LoRA权重更新），从而真正改变后续决策行为。这类似于生物记忆中“学习与记忆耦合”的特点：经验最终反映在执行计算的同一基质（模型参数）上。

## 2. 提出的方法论

### 2.1 核心思想：快速权重展开（Fast-Weight Rollout）

- 定义一个代理决策过程，其中策略依赖于三个部分：
  - **工作上下文** \(h_t\)：当前回合的交互历史（LLM的输入/输出token序列）。
  - **显式记忆** \(m_t\)：可选的文本记忆（如摘要、检索结果）。
  - **参数记忆** \(\Delta_t\)：快速LoRA权重，可在回合内通过在线微调更新。
- 生成的动作为：
  \[
  a_t \sim \pi_{\theta_0 + \Delta_t}(\cdot | c_t)
  \]
  其中基模型参数 \(\theta_0\) 在回合内固定，\(\Delta_t\) 动态变化。
- 当上下文长度超过预算 \(L_{\text{max}}\) 时，触发记忆写入模式：模型根据当前会话生成结构化的QA对（提取动作），然后对这些QA对进行轻量级在线SFT，更新LoRA权重 \(\Delta_t\)。后续动作从更新后的策略 \(\pi_{\theta_0+\Delta_{t+1}}\) 采样。
- 提取动作本身也被视为一种动作，可以通过强化学习优化基模型，使其产生更有助于后续在线适应的监督数据。

### 2.2 关键技术细节

- **记忆提取提示（Memory-writing prompt）**：当上下文预算耗尽时，添加一个特殊提示 \(d\)，要求模型从当前会话中提取“基于事实的SFT QA对”。提取结果以JSON格式输出。
- **在线SFT更新**：使用SGD，学习率 5×10⁻⁴，5个epoch，batch size 16。该更新仅调整LoRA的系数矩阵 \(B\)，投影矩阵 \(A\) 冻结。
- **SVD初始化**：对Transformer FFN层的目标权重矩阵 \(W\) 进行奇异值分解 \(W = U\Sigma V^\top\)，取前 \(r\) 个右奇异向量和奇异值：\(A_0 = \Sigma_r V_r^\top\)，\(B_0 = 0\)。这样初始 LoRA 子空间覆盖了预训练权重中能量最高的方向，加速在线收敛。理论证明（Theorem 1）表明该初始化在期望上优于随机高斯初始化。
- **RL优化目标**：使用基于结果奖励的策略梯度，但通过 stop-gradient 操作阻止梯度流入在线更新过程。梯度只更新基模型参数 \(\theta_0\)，使得RL同时提升普通任务动作和记忆提取动作的质量。

- **理论创新**：将记忆提取动作纳入RL优化，使基模型学会生成有助于自身后续适应的监督数据（“元学习”视角）。

- **实验充分**：覆盖多样任务、多个模型规模、多种消融，结果统计显著。
- **实用性强**：在主流水准上获取性能提升的同时，保持了可接受的推理开销（在LongMemEval-S上比检索更快）。
