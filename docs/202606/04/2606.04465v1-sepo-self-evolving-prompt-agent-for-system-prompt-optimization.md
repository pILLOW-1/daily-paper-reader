## 摘要
系统提示优化在不修改底层模型的情况下改善智能体行为，生成可读的、与模型无关的指令。现有方法构建一个提示代理来优化任务智能体的系统提示，但提示代理自身的系统提示仍由人工设计且固定不变。我们提出自进化提示优化（SePO），将提示代理自身的系统提示与任务智能体的系统提示一同作为优化目标。SePO采用自指涉设计：单个提示代理在开放式进化搜索中同时改进任务智能体的系统提示及其自身，该搜索维护一个候选提示存档作为垫脚石。训练分两个阶段：预训练在多任务池上进化提示代理，微调则将其应用于目标任务。在涵盖数学（AIME'25）、抽象推理（ARC-AGI-1）、研究生水平科学（GPQA）、代码生成（MBPP）和逻辑谜题（数独）的五个基准测试中，SePO持续优于Manual-CoT、TextGrad和MetaSPO，相较于Manual-CoT将平均准确率提升了4.49个百分点。预训练获得的提示优化技能还能泛化到预训练混合任务之外的任务，而非记忆每个任务的提示。

## Abstract
System prompt optimization improves agent behavior without modifying the underlying model, yielding human-readable, model-agnostic instructions. Existing methods build a prompt agent that refines task agents' system prompts, yet leave the prompt agent's own system prompt hand-engineered and fixed. We propose Self-Evolving Prompt Optimization (SePO), which treats the prompt agent's own system prompt as an optimization target alongside task agents' system prompts. SePO adopts a self-referential design. A single prompt agent improves both task agents' system prompts and its own under an open-ended evolutionary search that maintains an archive of candidate prompts as stepping stones. Training proceeds in two stages: pre-training evolves the prompt agent on a multi-task pool, and fine-tuning then applies it to a target task. Across five benchmarks spanning math (AIME'25), abstract reasoning (ARC-AGI-1), graduate-level science (GPQA), code generation (MBPP), and logic puzzles (Sudoku), SePO consistently outperforms Manual-CoT, TextGrad, and MetaSPO, improving the average accuracy by 4.49 points compared to Manual-CoT. The prompt optimization skill from pre-training also generalizes to tasks beyond the pre-training mixture, rather than memorizing per-task prompts.

## 1. 核心问题与整体含义（研究动机与背景）
系统提示优化能在不修改底层模型的情况下改善智能体行为，输出可读且模型无关的指令。现有方法（如 TextGrad、MetaSPO、PromptBreeder）都依赖一个“提示代理”来为任务智能体生成并改进系统提示，但**提示代理自身的系统提示却始终是手工设计且固定不变的**。这意味着优化永远受限于人类工程师的设计上限，且无法从多任务经验中积累普适的优化技能。  
本文提出 **SePO（Self-Evolving Prompt Optimization）**，通过一个**自指涉（self-referential）闭环**，让提示代理像改进任务智能体一样改进自己的系统提示，从而将提示优化转化为一个可学习、可积累的技能。

## 2. 方法论：核心思想、关键技术细节与流程
### 2.1 核心思想
- 将提示代理视为一个**特殊的任务智能体**，其任务是“改进任务智能体的系统提示”。  
- 用**同一套开放式进化搜索过程**同时优化两类系统提示：任务智能体的提示 \(p\) 和提示代理自身的提示 \(\tilde{p}\)。

### 2.2 关键技术细节
1. **自指涉闭环**：  
   - 在预训练阶段，提示代理的当前系统提示 \(\tilde{p}^{(t)}\) 作为“父代”被采样，通过调用自身（复制体）生成候选子代 \(\tilde{p}’\)；若子代在改进其他任务智能体上表现更优，则被收入档案。  
   - 这就实现了“提示代理改进其自身的系统提示”的自我参照。

2. **开放式进化搜索**（受 Zhang et al. 2026 启发）：  
   - 维护一个候选提示档案（archive），允许早期提示作为后续改进的垫脚石。  
   - 父代选择采用**带子代数量惩罚的软最大值**，避免同一提示被过度采样。  
   - 子代评分基于相对于父代的准确率提升（或相对提升率 RER）。  
   - 档案准入采用 `keep_better` 策略：只有分数不低于父代（考虑噪声容忍度）的子代才能加入。

3. **两阶段训练流程**：  
   - **预训练**：在多任务池上进化提示代理自身的系统提示，使其获得通用的提示优化技能。  
   - **微调**：固定预训练后得到的提示代理系统提示 \(\tilde{p}^*\)，用同样的进化过程优化特定目标任务的系统提示 \(p\)。

### 2.3 算法流程（文字描述）
```
输入：阶段（预训练/微调）、种子提示 p^(0)、代数 G、每代子代数 K
输出：最佳进化提示 p*
初始化档案 A = {p^(0)}
for t = 1 to G:
   并行生成 K 个子代：
        从 A 中采样父代 p
        通过提示代理（预训练时使用当前自己的提示 p，微调时使用固定 p*）生成子代 p'
        评估 p' 的分数，若满足准入标准则加入 A
返回 A 中最高分提示 p*
```

## 7. 优点
- **自指涉设计创新**：首次将提示代理自身也纳入优化循环，突破了固定优化器的天花板。  
- **两阶段训练范式**：预训练积累通用技能，微调专注单任务，既降低成本又提高泛化。  
- **可解释性与安全性**：只修改自然语言提示，可审计；档案准入策略只允许改善方向的变更，防止退化。  
- **开源**：代码已公开，可复现。  
- **成本可控**：SePO-Generalist 的预训练成本可被多次微调摊分。
