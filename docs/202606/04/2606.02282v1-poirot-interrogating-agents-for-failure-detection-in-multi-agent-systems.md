## 摘要
将大型语言模型编排成多智能体系统（LLM-MAS）打开了显著的推理能力，然而，那些难以表征的新兴故障和幻觉阻碍了它们在安全关键领域的部署——新兴人工智能法规使这一差距在法律上站不住脚。现有的评估范式存在一个共同缺陷：集中化判断会创造单点故障，并且需要领域特定专业知识。在此，我们提出POIROT，一种协议，它重新利用系统自身的智能体作为其诊断层，利用架构中已经存在的认知多样性。在评估的设置中，POIROT优于单LLM评估器基线，其增益随问题复杂性（OR = 1.60，p = 0.008）、智能体数量和故障维度而扩大，并在复合故障条件下持续存在。这些结果表明，安全监督不必外部化：执行角色的智能体携带足够的集体智慧来审计它。我们将POIROT作为开源库与BLAME（一个用于安全关键多智能体系统中故障归因的基准）一起发布。

## Abstract
Orchestrating Large Language Models into Multi-Agent Systems (LLM-MAS) has unlocked remarkable reasoning capabilities, yet emergent failures and hallucinations that resist characterisation block their deployment in safety-critical domains -- a gap made legally untenable by emerging AI regulation. Existing evaluation paradigms share a common flaw: centralised judgment creates single points of failure and demands domain-specific expertise. Here we present POIROT, a protocol that repurposes a system's own agents as its diagnostic layer, leveraging the epistemic diversity already present in the architecture. Across evaluated settings, POIROT outperforms single-LLM evaluator baselines, with gains that scale with problem complexity (OR = 1.60, $p = 0.008$), agent count, and fault dimensionality, persisting under compound fault conditions. These results demonstrate that safety oversight need not be externalised: the agents executing a role carry sufficient collective intelligence to audit it. We release POIROT as an open-source library alongside BLAME, a benchmark for fault attribution in safety-critical multi-agent systems.

## 2. 方法论：核心思想、技术细节与流程

- **核心思想**：将系统原有的智能体（而非外部评估器）重新用作诊断层，通过结构化审问（peer interrogation）和加权投票协议，利用智能体间的认知多样性实现分布式故障归因。

  3. **同侪审问**（Phase III）：智能体交换自我评估报告，通过结构化对话对比解释，分离“观察”与“归因”，不进行公开投票。
  4. **私密投票**（Phase IV）：每个智能体在危险空间中私密发射二元归因向量 v<sub>i</sub> ∈ {0,1}<sup>N</sup>，防止策略性对齐。
  5. **危险感知聚合**（Phase V）：采用**距离加权共识**机制聚合投票。每个智能体 A<sub>i</sub> 的规范位置为 p<sub>i</sub>（仅在第 i 维为 1）。Hamming 距离 d<sub>H</sub>(p<sub>i</sub>, v<sub>i</sub>) 衡量结构偏离度，权重公式：
     \[
     w_i = \beta + \frac12\left(1 - \frac{d_H(p_i, v_i)}{N}\right), \quad \beta=0.25

## 6. 主要结论与发现

- POIROT 在所有基准和模型上**始终优于单 LLM 基线**，且优势随**问题复杂度**（OR=1.60, p=0.008）、智能体数量和故障维度增加而扩大。
- 在复合故障（k>1）下，所有方法的绝对准确率显著下降（CORTEX 最好仅 28.8%），但 POIROT 在 3/4 模型中仍保持相对优势。
- 无单一模型在所有故障类型和架构中占据主导——归因难度与模型规模并非简单线性关系，取决于故障特征与模型推理模式间的交互。
- 个体智能体自我评估的准确率**系统性低于 POIROT 聚合结果**（差距 14–21 个百分点），证明结构化聚合的必要性。
- 距离加权聚合有效减少了上下文饱和、单一评估者偏差等问题。

## 7. 优点

- **去中心化设计**：避免集中式评估的单点故障和领域知识依赖，充分利用系统已有的认知异质性。
- **结构化协议**：自我评估→私密审问→私密投票→加权聚合的流程，分离观察与归因，防止策略性对齐。
- **理论保障**：权重公式确保最大权重不超过 0.75，防止单一智能体主导；Hamming 距离反映结构偏离度，具有直观解释。
- **实用性强**：开源为 Python 库（`pip install poirot-framework`），兼容 LangChain，无需修改原始智能体架构；同时发布 BLAME 基准，支持社区扩展。
- **实验设计严谨**：在多种安全关键领域验证，使用逻辑回归进行统计推断，并提供详细的每场景准确率表格（附录 D）。

## 8. 不足与局限

- **复合故障归因能力薄弱**：即使使用 POIROT，CORTEX 多故障注入下的最高准确率仅 28.8%，远未达到部署标准。
- **模型能力瓶颈**：当底层 LLM 能力较弱时（如 GPT-OSS 20B），POIROT 的增益微弱甚至为负（在某些场景不如基线），说明协议对智能体推理质量有较高要求。
- **未与人类专家直接比较**：虽然指出 LLM-as-a-judge 在开放任务中与人类一致率超过 80%，但未在安全关键故障归因任务中系统性地对比人类水平。
- **未考虑恶意共谋**：投票隐私可防止策略对齐，但未评估智能体之间通过串谋破坏诊断的可能性。
- **权重函数简化**：固定 β=0.25，仅依赖 Hamming 距离；未探索更复杂的动态权重（如基于历史准确率、置信度或语义相似度）的效果。
- **单会话评估**：仅针对单个会话内的故障归因，未评估跨会话知识积累或持续诊断场景。
