## 摘要
自进化智能体通过从过往执行中提炼经验并在未来任务中重用这些经验，随时间推移不断改进。现有系统将这些经验表示为注入智能体上下文中的自然语言文本，或表示为可作为可调用工具暴露的代码。然而，这两种表示之间的选择通常在设计时做出，而非源于经验本身的特性，导致人们对其间的权衡理解不足。我们首次进行了受控研究，在相同经验集上隔离文本记忆和代码记忆。结果表明，这两种形式在构建成本、执行效率和可迁移性方面表现出互补的权衡关系，因此单一表示都不足以胜任。在这些发现的指导下，我们提出了Metis，一种基于分层双表示记忆的自进化智能体系统。Metis将文本经验组织为执行计划、环境事实和常见陷阱，并有选择地将重复出现的计划结晶为经过验证的可调用工具。这种设计结合了文本记忆的广泛适用性和代码记忆的执行效率，同时仅在重复使用证明合理时才产生工具生成成本。我们在AppWorld（一个针对交互式智能体的挑战性基准）上评估了Metis。结果表明，与ReAct相比，Metis将任务准确率提高了最多20.6%，同时将执行成本降低了最多22.8%。与代表性的自进化智能体系统相比，Metis在准确率、执行效率和记忆构建成本之间持续实现了更好的平衡。

## Abstract
Self-evolving agents improve over time by distilling experience from past executions and reusing it in future tasks. Existing systems represent such experience either as natural-language text injected into the agent context or as code exposed as callable tools. However, the choice between these representations is typically made at design time rather than derived from the characteristics of the experience itself, leaving the trade-offs between them poorly understood. We present the first controlled study that isolates text memory and code memory over an identical set of experiences. Our results show that the two forms exhibit complementary trade-offs in construction cost, execution efficiency, and transferability, such that neither representation alone is sufficient. Guided by these findings, we propose Metis, a self-evolving agent system built on a hierarchical dual-representation memory. Metis organizes textual experience into execution plans, environment facts, and common pitfalls, and selectively crystallizes recurring plans into validated callable tools. This design combines the broad applicability of text memory with the execution efficiency of code memory while incurring tool-generation cost only when justified by repeated reuse. We evaluate Metis on AppWorld, a challenging benchmark for interactive agents. The results show that Metis improves task accuracy by up to 20.6% over ReAct while reducing execution cost by up to 22.8%. Compared with representative self-evolving agent systems, Metis consistently achieves a better balance between accuracy, execution efficiency, and memory-construction cost.

- **整体含义**：发现文本记忆构建成本低、可迁移性好，但执行效率低；代码记忆执行效率高，但构建成本高、可迁移性差。因此提出**层次化双表示记忆系统Metis**，以文本记忆为基础层，有选择地将重复出现的计划提升为代码工具，实现准确率、执行效率与构建成本的良好平衡。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **双表示记忆层次结构**：维护结构化文本记忆库（`Mtext`）和代码记忆库（`Mcode`）。
- **选择性代码提升机制**：仅将明确显示重复使用模式且稳定的文本执行计划（Execution Plan）转化为代码工具，而非对所有经验进行编码。
- **差异化文本记忆**：将文本经验分为三类：**执行计划**（可重用子例程模板）、**环境事实**（与任务无关的约束）、**常见陷阱**（结构化失败模式）。三类经验分别具有不同作用域和使用方式。
- **自进化循环**：执行 → 双路径反思（文本反思 + 模式感知代码生成）→ 记忆更新 → 未来任务检索重用。

### 关键技术细节
1. **差异化文本反思（Differentiated Text Reflection）**：
   - 反思器本身是一个有限推理循环的智能体，可访问环境工具。
   - 对成功任务：检查低效并生成效率提升条目；对失败任务：分析原因并生成纠正性陷阱或警告性事实。
   - 基于最近N个任务的查询分布制定计划，避免过拟合单个任务。
   - 记忆维护：合并冗余条目、失效替换（使用失效位而非原地编辑）。

2. **模式感知代码生成（Pattern-Aware Code Generation）**：
   - **编码单元**：仅从**执行计划**（文本记忆）中编码，不直接从原始轨迹编码。每个计划携带候选缓冲区`B(p)`、相关任务历史`R(p)`、已注册工具集合`D(p)`。
   - **重复性提升门**：当计划被选择的次数达到阈值θ时触发编码。编码器接收计划主体、候选查询、相关查询、当前工具库和沙盒环境，**刻意排除原始轨迹**以避免过拟合。
   - **工具准入**：生成的工具必须经过沙盒中的依赖闭包检查、编译测试和功能测试（至少两个不同查询支持，任务变量参数化）。仅通过检查的工具才被加入代码记忆库。

3. **记忆管理器（Memory Manager）**：
   - 联合选择：先通过嵌入检索获得文本条目和工具的候选池，再使用轻量级LLM管理器联合选择最相关的条目与工具。选中的计划自动引入其关联工具。

4. **反思框架（Reflection Harness）**：
   - 渐进式披露：轨迹被压缩为紧凑视图（头部+尾部截断），反思器可要求展开特定步骤。
   - 依赖闭包：在执行上下文注入前，静态扫描工具依赖，确保完整注入。
   - 工具准入保护：新工具必须通过编译和依赖闭包检查，允许一次修正机会。

## 6. 主要结论与发现

1. **文本记忆与代码记忆互补**：文本构建成本低、可迁移性好，但执行效率低；代码执行效率高，但构建成本高、可迁移性差。
2. **Metis在准确率、执行效率、构建成本间取得最优平衡**：在两种拆分上均取得最高准确率（官方60.1%，重采样66.1%），同时消耗最少执行令牌和ReAct轮数。反思成本低于最强基线SkillX（官方7.9M vs 9.4M）。
3. **选择性代码提升优于无条件编码**：急切编码（Eager）导致构建成本增加47%，准确率下降3.5个百分点，且工具调用率低（41% vs 完整Metis的56%）。
4. **差异化文本记忆有效提升鲁棒性**：三种类型经验（计划、事实、陷阱）分别应对不同情况，防止过概化或过细化。
5. **代码工具通过重复性门和沙盒验证确保质量和可迁移性**：在重采样拆分上表现与SkillX相当，但在官方拆分（分布偏移）上优势显著（+8.3 vs +3.0），说明其工具具有更好的泛化能力。

## 7. 优点

- **首创性**：首次对经验表示形式进行受控研究，隔离文本与代码，揭示了二者在三个维度上的互补权衡。

- **技术细节扎实**：差异化文本记忆（计划/事实/陷阱）避免扁平化存储；重复性提升门避免过拟合；反思框架渐进式披露提高效率；依赖闭包检查确保工具可执行。
- **实验设计严谨**：多种设置（官方/重采样/验证集）、控制任务难度（共同解决子集）、公平比较（统一反射模型、任务顺序）、充分消融。
- **结果全面**：报告准确率、执行令牌、ReAct轮数、反思成本、重用率等多个维度，全面评估系统性能。
