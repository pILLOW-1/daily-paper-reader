## 摘要
世界模型为长期规划的LLM智能体提供了一种原则性的方式来实现前瞻性：在行动执行前预测其后果。然而，不可靠的前瞻性可能会被忽视、误用，甚至降低下游决策的质量。在本文中，我们引入了WorldEvolver，一种自进化的世界模型框架，它在保持下游智能体和所有模型参数冻结的同时，修订其部署时的上下文。WorldEvolver集成了三个模块：（i）情景记忆，通过基于检索的模拟利用真实的行动转换；（ii）语义记忆，从预测-观察不匹配中提取持久的启发式规则；以及（iii）选择性前瞻，在将低置信度预测整合到智能体推理上下文之前进行过滤。我们在ALFWorld和ScienceWorld上评估了WorldEvolver，在Word2World上测量世界模型预测准确率，在AgentBoard上测量下游智能体成功率。大量实验表明，WorldEvolver在三个主干网络上实现了最高的预测准确率，并在下游智能体成功率上领先其他世界模型基线，证明了测试时记忆修订同时提高了预测保真度和规划性能。

## Abstract
World models offer a principled way to equip long-horizon LLM agents with foresight: predictions of action consequences before execution. However, unreliable foresight can be ignored, misused, or even degrade downstream decision-making. In this paper, we introduce WorldEvolver, a self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen. WorldEvolver integrates three modules: (i) Episodic Memory, which exploits real action transitions through retrieval-based simulation; (ii) Semantic Memory, which extracts persistent heuristic rules from prediction-observation mismatches; and (iii) Selective Foresight, which filters low-confidence predictions before integrating them into agent reasoning context. We evaluate WorldEvolver on ALFWorld and ScienceWorld, measuring world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard. Extensive experiments show that WorldEvolver achieves the highest prediction accuracy across three backbones and leads other world model baselines on downstream agent success rate, demonstrating that test-time memory revision enhances both predictive fidelity and planning performance.

### 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：语言智能体（LLM Agent）在长程任务中常借助世界模型进行前瞻性预测（行动后果预测），但预测不可靠时会被智能体忽略、误用，甚至恶化下游决策。现有世界模型在部署后要么参数冻结，无法适应环境分布偏移；要么通过梯度更新适应，但计算昂贵且可能导致灾难性遗忘。
- **研究动机**：智能体与环境互动过程中自然产生两类可用信号——已执行的真实轨迹（“发生了什么”）和预测—观察不一致（“模型哪里理解错了”）。若能将这些信号以可审计的上下文形式保留，无需更新模型参数即可持续改进预测质量，从而提升智能体规划性能。
- **核心含义**：提出一种学习方式——通过在**测试时修订记忆内容**而非更新参数，让世界模型在部署期间自我进化，同时保持下游智能体和所有模型参数冻结。

### 论文提出的方法论

- **核心思想**：将世界模型预测过程解耦为三个互补的机制，全部通过非参数记忆（prompt 级别的上下文）实现，不更新模型权重。

- **关键技术细节**：
  1. **情景记忆（Episodic Memory, $M_E$）**：存储已执行的真实转换三元组 $(o_i, a_i, o_{i+1})$。给定候选动作 $a_t$，通过动作 token 集合的 Jaccard 相似度检索最相似的 $k_{ME}$ 个历史转换，作为上下文提示给世界模型。这属于“利用”（exploitation）——从过去经验中直接类比。
  2. **语义记忆（Semantic Memory, $M_S$）**：将预测与观察的不匹配转化为持久性启发式规则。首先通过因子化函数 $g$ 将原始观察文本转换为三元组（subject, predicate, object），比较预测 $\hat{o}_{t+1}$ 和真实 $o_{t+1}$ 的三元组差异；若不匹配，则用 LLM critic 生成描述“哪些属性不应变化”的保持规则，并赋予证据分数 $e_i$。只有 $e_i>0$ 的规则保留在上下文中。这属于“探索”（exploration）——从失败中提炼抽象知识。
  3. **选择性远见（Selective Foresight, $F_t$）**：计算世界模型预测输出 token 的几何平均概率作为置信度 $q_t = \exp(\frac{1}{n}\sum \log p_\theta(y_i))$，仅在 $q_t \geq \tau$ 时将预测暴露给智能体，否则提供空信号 $\emptyset$。避免低质量预测误导决策。

- **算法流程（单步闭环）**：
  1. 智能体先从当前状态 $s_t$ 采样草案动作 $a_t^{(0)}$。
  2. 从情景记忆检索与 $a_t^{(0)}$ 最相似的 $k_{ME}$ 个转换，加上语义记忆规则，送入冻结的世界模型 $W_\theta$。
  3. 得到预测 $\hat{o}_{t+1}$ 和置信度 $q_t$；若 $q_t < \tau$，则不提供远见。
  4. 智能体根据 $s_t$ 和（若有）远见 $F_t$ 采样最终执行动作 $a_t = a_t^{(1)}$。
  5. 如果最终动作 $a_t \neq a_t^{(0)}$，需用 $a_t$ 重新查询世界模型获取对齐的预测。
  6. 执行 $a_t$，观察 $o_{t+1}$；将 $(o_t, a_t, o_{t+1})$ 追加到情景记忆；检查预测与观察是否匹配，若不匹配则通过 LLM critic 生成或积累规则更新语义记忆。

### 优点

- **无需参数更新**：所有进化发生在 prompt 级别，避免了梯度更新的计算成本和遗忘风险，易于部署。
