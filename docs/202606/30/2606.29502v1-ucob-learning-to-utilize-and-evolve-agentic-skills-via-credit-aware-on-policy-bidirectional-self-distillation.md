## 摘要
技能记忆可以通过重用过去的经验作为文本引导来改善智能体强化学习，但检索到的技能并非全知全能：它们可能在一个状态下有帮助，而在另一个状态下却误导相同的策略。这使得常见的特权教师假设变得脆弱，即技能条件提示可以被视为无技能提示的固定教师。我们提出了UCOB，一个通过信用感知的在策略双向自蒸馏学习利用和演化智能体技能的框架。UCOB将技能条件和无技能提示视为同一模型的两个在策略上下文视图，在同一任务和锚定状态下比较它们的剩余回报，并将较高回报的视图作为局部教师。这种局部信用信号内化了有用的技能条件行为，纠正了误导性的技能使用，并指导任务/状态技能记忆更新、效用感知检索和反思自训练。在包括ALFWorld、WebShop和Search-QA在内的智能体任务上的实验表明，UCOB在不同模型规模上优于无技能RL、技能记忆基线和自蒸馏方法，在ALFWorld和WebShop上分别比最强基线高出23.5和18.0个百分点。消融实验和分析进一步验证了其核心机制和效率。

## Abstract
Skill memories can improve agentic reinforcement learning by reusing past experience as textual guidance, but retrieved skills are not oracular: they may help in one state while misleading the same policy in another. This makes the common privileged-teacher assumption fragile, namely that a skill-conditioned prompt can be treated as a fixed teacher for the no-skill prompt. We introduce UCOB, a framework for learning to utilize and evolve agentic skills via credit-aware on-policy bidirectional self-distillation. UCOB treats skill-conditioned and no-skill prompts as two on-policy context views of the same model, compares their return-to-go within the same task and anchor state, and uses the higher-return view as the local teacher. This local credit signal internalizes useful skill-conditioned behavior, corrects misleading skill usage, and guides task/state skill memory updates, utility-aware retrieval, and reflection self-training. Experiments on agentic tasks, including ALFWorld, WebShop, and Search-QA, show that UCOB outperforms skill-free RL, skill-memory baselines, and self-distillation methods across model scales, with up to 23.5 and 18.0 point gains over SOTA baselines on ALFWorld and WebShop. Ablations and analyses further validate its core mechanisms and efficiency.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：语言智能体在长程交互任务中依赖技能记忆（skill memory）来复用经验，但检索到的技能并非始终可靠。同一个技能在不同状态下可能有益也可能有害，这使得“技能条件提示可作为无技能提示的固定教师”这一特权教师假设变得脆弱。
- **背景与动机**：现有方法（如 Skill-SD、SDAR）假设技能条件分布始终优于无技能分布，并单向蒸馏技能→无技能。然而作者通过诊断发现：技能条件视图并不总是更好，甚至在训练中可能更差；即使让技能条件视图进行在策略（on-policy） rollout，也无法消除这种歧义。因此，需要一种局部、信用感知的方法来决定何时信任技能、何时纠正技能。

## 2. 方法论

### 核心思想
- **UCOB** 将技能条件提示（+）和无技能提示（0）视为同一在线策略的两个上下文视图，而非固定教师-学生关系。
- 通过同任务、同锚定状态（anchor state）下的剩余回报（return-to-go）比较，选择较高回报的视图作为局部教师，进行双向自蒸馏。
- 同时利用局部回报差距更新技能记忆的效用、指导检索，并训练反思（reflection）技能写入器，形成闭环。

### 关键技术细节
1. **双层级技能记忆与混合 Rollout**
   - 维护任务级（task-level）和状态级（state-level）技能池，在线扩展。
   - 使用 UCB 评分进行效用感知检索，公式：\(R_p(m; s_t) = \alpha \cdot \text{sim}(q_p(s_t), k_m) + (1-\alpha)\left(U(m) + \eta\sqrt{\frac{\log(N_p+1)}{n_m+1}}\right)\)。
   - 混合 rollout：每个任务组中一半轨迹使用技能条件提示，另一半使用无技能提示，均进行 RL 更新。

2. **锚定状态分组**
   - 基于 GiGPO 的锚定状态机制，将同一任务、同一锚定状态的记录归为一组 \(C(u, \tilde{s})\)。
   - 每条记录包括状态、分支、响应、回报等。

3. **信用感知双向自蒸馏（CBSD）**
   - 对每个锚定状态组，选择回报最高的记录作为参考 \(\rho^*\)。
   - 如果回报差 \(\Delta_e > \epsilon_{\text{CBSD}}\)，则形成蒸馏对：参考视图向相反视图蒸馏。
   - 使用 top-K token 支持匹配：在参考视图的 top-K 支持集上计算 KL 散度。
   - 结合置信门控 \(g_{e,j}\) 和权重 \(w_e = \text{clip}(\Delta_e / \tau_{\text{CBSD}}, 0, w_{\max})\)。
   - 损失函数：\(\mathcal{L}_{\text{CBSD}} = \frac{1}{Z_{\text{CBSD}}}\sum_{e,j} \chi_{e,j} D_{\text{topK}, e,j}\)，其中 \(\chi_{e,j} = m_{e,j} w_e g_{e,j}\)。

4. **技能记忆演化**
   - 写入技能：任务级技能来自 rollout 组反思，状态级技能来自同锚定状态高/低回报对比。
   - 更新效用：基于成功改进率的指数移动平均 \(U(m) \leftarrow (1-\beta_U)U(m) + \beta_U \delta_m\)。
   - 技能写入器自训练：利用效用导出优势进行策略梯度更新 \(\mathcal{L}_{\text{refl}}\)。

5. **整体损失**
   - \(\mathcal{L} = \mathcal{L}_{\text{RL}} + \lambda_{\text{CBSD}}\mathcal{L}_{\text{CBSD}} + \lambda_{\text{refl}}\mathcal{L}_{\text{refl}} + \beta_{\text{KL}}\mathcal{L}_{\text{KL}}\)。

### 理论视角（简要）
- 证明了 CBSD 在一阶局部改进方向：将低值分支向高值分支插值可提高局部优势代理。
- 固定单向蒸馏在负差距时会导致负向更新，而双向选择可确保局部更新为正。

## 6. 主要结论与发现

1. **技能条件教师不可靠**：诊断显示技能视图并非始终优于无技能视图，即使进行在策略 rollout 也是如此；教师方向应取决于局部回报差距。
2. **CBSD 提升性能**：信用感知的双向蒸馏在 ALFWorld 上比最强基线（Skill1）高 23.5 个百分点，在 WebShop 高 18.0 个百分点；在 Qwen3-1.7B 上效果尤为显著。
3. **技能记忆演化有效**：技能池在线扩展，检索效用保持正向，有用技能比例保持非平凡，反思优势信号持续活跃。
4. **双向蒸馏使两视图共同进化**：UCOB 同时提升技能和无技能评估视图的成功率，而固定方向法则不能。
5. **局部信用优于全局固定方向**：消融证实固定单向蒸馏弱于双向蒸馏，即使有回报门控。

## 8. 不足与局限

- **搜索 QA 上的提升有限**：在 Search-QA 上 UCOB 仅保持竞争力，未全面超越最佳基线（平均准确率最大差距仅 0.8 个点），说明双向蒸馏在短 horizon、单步决策场景下收益较小。
- **理论分析局部性**：论文仅给出一步更新下的局部改进保证，未提供全局收敛性证明（作者明确说明）。
