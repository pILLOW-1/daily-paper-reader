## 摘要
AI代理依赖由技能、工具和工作流组成的技能集来解决复杂问题。持续改进这一技能集对于适应新任务至关重要。然而，现有的优化方法通常需要真实标签的验证集，而在实际部署场景中，此类标注数据难以获取。为解决这一问题，我们提出了回顾性技能优化（RHO），一种仅利用过去轨迹进行自我监督的方法，以优化代理技能集。具体而言，RHO从过去轨迹中选择一个多样化的困难任务核心集，并并行重新求解。代理通过自验证和自一致性分析这些回滚，然后生成候选技能集更新，并通过自身的成对自偏好选择最有效的更新。我们在软件工程、技术工作和知识工作三个不同领域评估了RHO。值得注意的是，单轮优化将SWE-Bench Pro上的通过率从59%提升至78%，且无需任何外部评分。此外，我们的分析表明RHO有效针对先前的失败模式。因此，优化后的技能集改变了代理的行为模式，并在长时间会话中保持更高的准确性。

## Abstract
AI agents rely on a harness of skills, tools, and workflows to solve complex problems. Continually improving this harness is essential for adapting to new tasks. However, existing optimization methods typically require ground-truth validation sets, yet such labeled data is difficult to acquire in practical deployment settings. To address this problem, we introduce Retrospective Harness Optimization (RHO), a self-supervised method that optimizes the agent harness using only past trajectories. Specifically, RHO selects a diverse coreset of challenging tasks from past trajectories and re-solves them in parallel. The agent analyzes these rollouts using self-validation and self-consistency, then generates candidate harness updates and selects the most effective one by its own pairwise self-preference. We evaluate RHO across three diverse domains, spanning software engineering, technical work, and knowledge work. Notably, a single optimization round improves the pass rate on SWE-Bench Pro from 59% to 78% without any external grading. Furthermore, our analysis demonstrates that RHO effectively targets prior failure modes. As a result, the optimized harness alters the agent's behavior patterns and sustains higher accuracy during long-horizon sessions.

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：利用 Agent 自身对轨迹的**自偏好（self-preference）** 作为优化信号，通过回顾性分析过去失败和成功案例，生成并筛选出更优的 harness。
- **关键技术细节（三步流水线）** ：
  - **① Coreset Selection（核心集选择）** ：
    - 从大量历史轨迹中，利用**行列式点过程（DPP）** 挑选一个兼具**高难度**和**高多样性**的小规模子集（coreset size \(k=10\)）。
    - 用 LLM 裁判为每条轨迹给出难度分数 \(r_i\) 和文本描述，再计算描述嵌入的余弦相似度构建核矩阵 \(K = \text{diag}(e^{\tilde{r}}) S \text{diag}(e^{\tilde{r}})\)，通过参数 \(\theta=0.7\) 平衡难度与多样性。
  - **② Group Rollout（组回滚）** ：
    - 对每个核心集任务并行执行 \(G=3\) 次求解，生成多条轨迹。
    - 提取两个诊断信号：
      - **自验证（self-validation）** ：检查单条轨迹内部是否错误调用工具、错误假设等。
      - **自一致性（self-consistency）** ：比较不同轨迹之间是否存在分歧（如计划矛盾），高分歧通常表示不确定性。
    - 将两个诊断信号合并为改进指令 \(I_t\)。
  - **③ Best-of-N Harness Proposal（最佳候选提出）** ：
    - 基于改进指令，并行采样 \(N=3\) 个候选 harness（\(h_1 \dots h_N\)）。
    - 对每个候选，让 Agent 在核心集上重新求解，得到新轨迹。
    - 使用**成对自偏好**比较新轨迹与原始轨迹，计算相对优势分数 \(S_j = \frac{1}{|D_{\text{core}}|} \sum_t \text{rank}(t, \tau_t^{(j)}, \tau_t^{(0)})\)。
    - 仅当 \(S_j > 0\) 时接受最佳候选，否则保持原始 harness。

## 6. 论文的主要结论与发现
- **主要结论**：RHO 是一种有效的自监督 harness 优化方法，仅使用过去轨迹即可显著提升 Agent 性能，无需任何外部真实标注。
- **关键发现**：
  - 在 SWE-Bench Pro 上，单轮优化将 pass rate 从 **59% 提升至 78%**，Terminal-Bench 2 提升 5%，GAIA-2 提升 8%。
  - 优化后的 harness 会增加新的技能和工具，针对性修复典型失败模式（如 Go 工具链路径、Python 缓存清理等）。
  - 优化后 Agent 的行为模式发生改变：在 SWE-Bench 上更倾向于验证（Verify）动作，在其他数据集上更倾向于执行新工具。
  - 核心选择平衡难度与多样性至关重要，仅关注难度或覆盖都无法带来显著提升。
  - 自我验证和自我一致性两个诊断信号缺一不可，单独移除均导致性能下降。
  - 采用 Best-of-N 筛选可以避免部署低劣候选，即使最低分候选也优于基线。

## 7. 优点（方法或实验设计的亮点）
- **自监督框架**：完全摆脱对人工标注验证集的依赖，适合实际部署中连续学习。
- **全 Harness 优化**：不仅能更新记忆和指令，还能创建新的可执行工具和技能，优于仅更新内存/记忆的同类方法（如 Dynamic Cheatsheet）。
- **诊断信号设计**：通过组内执行产生自验证和自一致性两个互补信号，提供细粒度改进指导。
- **稳定筛选机制**：成对自偏好 + 严格正分数阈值，降低随机优化带来的退化风险。
- **实验设计完整**：跨领域、多基线、多消融、行为分析，且提供了详细的计算成本记录，有助于复现和比较。

## 8. 不足与局限
- **环境要求**：Group Rollout 需要任务环境可以干净重置并容忍多次执行，无法用于一次性、不可逆任务（如实际订单操作）。
- **假设前提**：假设 Agent 的能力主要通过可编辑的 harness（提示、技能、工具）体现，对于完全依赖模型内部参数的场景（如纯 Chat Agent）可能不适用。
- **偏差风险**：自偏好基于模型自身判断，可能放大已有的错误偏好或安全漏洞；需要人工审核敏感编辑。
- **实验覆盖局限**：仅测试了两个领域（软件工程、技术工作、知识工作），未涉及机器人控制、多轮对话等场景；仅在 GPT-5.5 上实验，泛化性未验证。
- **计算成本**：虽然比 Meta-Harness 的高预算版低，但仍需要数百次 Agent 调用，对资源有要求；且未分析在更大规模历史轨迹下的效率。
