## 摘要
LLM智能体的技能自进化方法旨在将执行轨迹转化为可复用的技能文档，但当前的流程通常每个任务只学习一条轨迹，在检查之前合并候选技能补丁，并在推理前加载完整技能库。我们提出SkillCAT，这是一个无需训练的框架，将该过程分为三个阶段。对比因果提取（CCE）为每个任务采样多条轨迹，并比较同任务的成功/失败对，以识别解释结果差异的证据。评估增强进化（AAE）在源任务克隆上重放每个候选补丁，并在分层技能补丁合并前仅保留改进或保持任务结果的补丁。拓扑感知任务执行（TTE）将进化后的技能编译为可路由的子技能拓扑，因此推理仅加载与任务相关的能力节点。我们在常见的智能体基准测试（包括SpreadsheetBench、WikiTableQuestions和DocVQA）上评估SkillCAT，并进一步测试跨模型和分布外泛化。在这些设置中，SkillCAT将基线平均得分提高了高达40.40%，展示了无需模型训练的可靠技能进化。

## Abstract
Skill self-evolution methods for LLM agents aim to turn execution trajectories into reusable skill documents, but current pipelines typically learn from one trajectory per task, merge candidate skill patches before checking them, and load the full skill corpus before inference. We propose SkillCAT, a training-free framework that separates this process into three stages. Contrastive Causal Extraction (CCE) samples multiple trajectories for each task and compares same-task success/failure pairs to identify evidence that explains outcome differences. Assessment-Augmented Evolution (AAE) replays each candidate patch on source-task clones and keeps only patches that improve or preserve task outcomes before hierarchical skill patch merging. Topology-Aware Task Execution (TTE) compiles the evolved skills into a routable sub-skill topology, so inference loads only the capability nodes relevant to the task. We evaluate SkillCAT on common agent benchmarks, including SpreadsheetBench, WikiTableQuestions, and DocVQA, and further test cross-model and out-of-distribution generalization. Across these settings, SkillCAT raises the average score over baselines by up to 40.40%, demonstrating reliable skill evolution without model training.

## 1. 核心问题与整体含义（研究动机和背景）

- 现有LLM智能体技能自进化方法（如Trace2Skill）存在三个关键缺陷：
  - **单轨迹偏差**：每任务仅采样一条轨迹，成功可能只是偶然策略，失败无法定位根本原因。
  - **未验证合并**：候选技能补丁直接合并，未在源任务上独立验证其效果，低质量或有害补丁可能混入。
  - **上下文过载**：进化后的技能库持续增长，推理时加载全部内容，增加提示长度并干扰任务相关规划。
- 论文旨在提出一种无需训练的框架，通过分离证据提取、补丁验证、测试时部署三个阶段，实现可靠且高效的技能自进化。

## 2. 论文提出的方法论

### 核心思想
- 将技能生命周期分解为三个独立可观测的阶段：对比因果提取（CCE）、评估增强进化（AAE）、拓扑感知任务执行（TTE）。
- 每个阶段针对性解决上述一个缺陷：CCE利用多轨迹对比提取因果证据；AAE通过源任务回放验证补丁后再合并；TTE编译可路由子技能拓扑，仅加载任务相关节点。

### 关键技术细节

#### 对比因果提取（CCE）
- 每任务采样K条轨迹（默认5种子），形成同任务成功/失败对比对。
- 定位因果分水岭（首次动作分歧点），提取该点周围的局部证据、失败原因和技能可编辑的经验记录。
- 若无严格对比对（全成功或全失败），可启用fallback使用单轨迹提取器，或跳过该任务。

#### 评估增强进化（AAE）
- 将每个候选补丁视为假设，在源任务克隆上回放，记录基线结果与回放结果。
- 定义四类得分：失败→成功（3分）、成功→成功（2分）、失败→失败（1分）、成功→失败（0分）。
- 通过阈值θ=2.0筛选保留补丁后，按得分层级从低到高分层合并（使用Trace2Skill的合并操作符），最终得到进化技能S*。

#### 拓扑感知任务执行（TTE）
- 离线将S*编译为核心技能（always-on）和可路由节点集（level-2段），节点包括原始正文、标题、关键词、摘要、依赖关系等元数据。
- 推理时：LLM路由器根据任务描述和路由预算（默认top_k=7）从拓扑摘要中选择相关节点，再经确定性扩展（依赖边、基础节点注入）后，将核心技能与节点正文拼接为路由技能Sc。

### 算法流程（文字说明）
1. 输入进化任务集X、种子集Z、基础技能S0、阈值θ、路由预算k。
2. 阶段1（CCE）：对每个任务xi，用所有种子运行得到轨迹集Ti，若混合结果则构造对比对，提取因果证据记录；否则根据fallback处理。
3. 阶段2（AAE）：将记录转为候选补丁，对每个补丁在源任务克隆回放，计算得分，保留aj≥θ的补丁，按得分层级分层合并得到S*。
4. 阶段3（TTE）：离线编译S*为拓扑（核心S◦、节点集V），在线对每个测试任务用LLM路由器选择节点，扩展后组装Sc，用Sc执行智能体。

## 6. 主要结论与发现

- SkillCAT在SpreadsheetBench-Verified上，Qwen3.5-35B-A3B Deepening设置下Vrf达55.50%，比Trace2Skill +Combined提高25.83个百分点；在Skill Creation下达54.50%，提升34.33个百分点。
- OOD泛化（WikiTableQuestions）中最高达84.47%准确率，DocVQA多模态任务上ANLS达0.9159，显著优于基线。
- 跨模型泛化：使用Qwen3.5作者技能，gemma-4-31B-it Vrf从39.00%提升至61.00%（Deepening）；gpt-5.4-mini也有提升。
- 消融证明三个模块均不可或缺：去除CCE或AAE导致性能下降（低于完整系统），去除TTE也损失9个点。
- CCE最佳种子数为5；AAE得分与下游性能单调正相关；TTE在top_k=7时达到55.50% Vrf并减少41.6%上下文。

## 7. 优点

- **无需训练**：完全基于提示和重放，不更新模型权重，降低了计算成本。
- **模块化设计**：三个模块独立解决特定问题，可单独替换或消融。
- **对比因果提取**：通过同任务成败对比，聚焦因果分水岭，避免单轨迹噪声。
- **源任务回放验证**：在克隆上评估每个补丁效果，避免有害合并。
- **拓扑感知路由**：推理时仅加载少量相关技能，降低上下文开销并提升准确性。
- **强大泛化能力**：跨模型、跨任务类型（表格、文档）均有效。

## 8. 不足与局限

- **种子数敏感**：性能随种子数先升后降（5种子最优），需要调参；大量种子增加采样时间。
- **路由依赖LLM**：TTE的路由器本身是LLM调用，可能引入额外开销或错误路由。
- **域覆盖有限**：仅在表格和文档任务上验证，未测试代码、网页操作等更广泛的智能体场景。
- **回放成本**：AAE需要在源任务克隆上重放每个补丁，当进化任务集大或克隆数多时，时间成本可能较高。
- **跨模型迁移效果不一**：对gpt-5.4-mini提升较小（+1.5~6.8个百分点），表明技能可迁移性受用户模型能力限制。
- **与Trace2Skill的公平性**：虽然对比了Trace2Skill，但SkillCAT使用了更多轨迹（多种子）和更复杂的后处理，对比时未完全控制计算资源（如推理次数）。作者在实验设置中尽量使条件一致，但工作量差异客观存在。
