## 摘要
多模态智能体通过工具使用在复杂推理任务上取得了显著进展，但仍受限于两个问题：静态预定义的工具库无法泛化到未见场景；不加区分的工具调用会带来冗余成本和噪声引发的错误。我们提出MetaForge，一种多模态智能体框架，它学会何时调用工具以及如何按需进化其工具集。MetaForge将智能体行为分解为四个耦合阶段：判断（判断是否值得使用工具）、检索（选择合适的工具）、适配（将工具参数落地到任务上下文中）和锻造（在线合成新技能并将其回收进工具库以供复用），形成闭环的“判断-检索-适配-锻造-回收”流程。一种统一的编排策略使智能体能够在直接回答、复用现有工具或锻造新工具之间进行选择。我们通过强化学习联合优化调用必要性、检索准确性、执行效果和锻造技能的可复用性，并加入显式的调用成本惩罚以抑制冗余调用。在12个基准测试中，MetaForge在准确性、效率和泛化性上持续超越16个基线，验证了从静态工具库向按需自进化的范式转变。

## Abstract
Multimodal agents have achieved notable progress on complex reasoning tasks through tool use, yet remain limited by two issues: statically predefined tool inventories fail to generalize to unseen scenarios, and indiscriminate tool invocation incurs redundant cost and noise-induced errors. We propose MetaForge, a multimodal agent framework that learns when to invoke tools and how to evolve its toolset on demand. MetaForge factorizes agentic behavior into four coupled stages: Decide (judging whether tool use is warranted), Retrieve (selecting suitable tools), Adapt (grounding tool parameters in task context), and Forge (synthesizing new skills online and recycling them into the tool library for reuse), forming a closed judge-retrieve-adapt-forge-recycle loop. A unified orchestration policy enables the agent to choose among answering directly, reusing existing tools, or forging new ones. We jointly optimize invocation necessity, retrieval accuracy, execution effectiveness, and forged-skill reusability via reinforcement learning, with an explicit invocation-cost penalty discouraging redundant calls. Across 12 benchmarks, MetaForge consistently surpasses 16 baselines in accuracy, efficiency, and generalization, validating a paradigm shift from static tool inventories to on-demand self-evolution.

## 2. 论文提出的方法论

### 核心思想
MetaForge将多智能体行为分解为四个耦合阶段，形成闭环：
- **Decide（判断）**：判断当前任务是否需要外部工具，还是可以直接回答。
- **Retrieve（检索）**：如果需工具，从动态工具库中选择合适的工具。
- **Adapt（适配）**：将工具调用参数适配到当前任务上下文（如图像索引、提示词等）。
- **Forge（锻造）**：当现有工具均无法满足需求时，在线合成新的可执行技能，验证后注册回工具库，供未来复用。

### 关键技术细节
- **工具库组成**：分为三类——可执行工具（OCR、代码解释器）、模型工具（专用视觉模型如GroundingDINO、SAM）、锻造工具（用户按需创建的可复用技能）。
- **在线工具锻造（Online Tool Forging）**：采用两阶段过程：
  1. **规划阶段**：锻造模型`G_φ`根据自然语言需求生成结构化规划（包含名称、描述、参数接口和所需脚本）。
  2. **实现阶段**：为每个脚本生成代码，形成三元组`(ms, ps, es)`（Markdown规范、JSON模式、可执行脚本）。
- **验证与注册**：候选锻造工具必须通过执行验证（编译通过、无错误）和语义验证（行为符合需求），通过后加入工具库。

### 强化学习优化（GRPO）
- 采用多轮GRPO（Group Relative Policy Optimization）进行训练。
- **复合奖励函数**包含四个部分：
  - **Retrieve/Adapt奖励**：答案是否与真实标签匹配（二元信号）。
  - **Decide奖励**：在正确回答的轨迹中，根据工具调用延迟归一化计算，鼓励少调用、低成本（效率排名）。
  - **Forge奖励**：鼓励正确轨迹中成功锻造并复用新工具。
  - **Format奖励**：强制输出格式合规（如工具调用语法、答案分隔符）。
- 优势函数通过组内奖励标准化计算，优化目标为裁剪代理目标加KL散度正则化。

### 容量约束工具池管理
- 为避免工具库无限膨胀占用上下文窗口，采用**语义去重**（合并功能重叠的锻造工具）和**基于使用频率的保留策略**（保留高使用频率或当前需求高的工具，设定容量上限K）。

## 6. 主要结论与发现

1. **准确率显著领先**：MetaForge在12个基准上，IID和OOD设置下均取得最佳平均准确率（88.14%和88.98%），全面超越所有基线（包括闭源GPT-5.4、Claude Sonnet 4.6）。

3. **效率-准确率平衡**：Decide奖励鼓励简洁调用路径，使交互轮次稳定在约2.3轮，同时保持高效率。
4. **工具选择集中可靠**：TUE最低（IID:1.30, OOD:1.12），工具成功率最高（IID:96.59%, OOD:98.24%），错误类型以环境类错误为主。
5. **主干无关性**：在Qwen、InternVL等不同架构和规模上训练，均观察到显著提升。

## 7. 优点

- **方法创新性**：首次提出“判断-检索-适配-锻造”闭环自进化范式，将工具使用从静态预定义推向按需动态扩展。
- **强化学习设计合理**：复合奖励函数同时优化正确性、效率、锻造和格式，Decide奖励的组内归一化确保不牺牲正确性换取速度。
- **工具池管理机制**：容量约束+语义去重+使用频率保留，防止规模膨胀并保持工具质量。

## 8. 不足与局限

- **技能形式限制**：每个锻造工具以可执行脚本实现，适用于代码处理、图表分析、数值计算等程序化操作。对于需要额外模型或外部资源（如视频合成）的任务可能超出当前设计。
- **评估模态覆盖不足**：仅评估图像-文本任务，未涵盖音频、视频、时间推理或交互环境。泛化到更丰富的多模态设置尚待验证。
- **效率目标单一**：优化目标聚焦于延迟，但实际部署中工具调用还涉及货币成本和上下文窗口使用。未来可集成这些因素，实现更综合的平衡。
- **锻造质量依赖基模**：锻造模型使用Qwen3-VL-235B，虽然强大但可能是资源瓶颈。更小模型下性能未知。
- **工具池管理策略**：使用简单的启发式（使用频率上四分位数阈值+组大小排名），可能存在更优策略。
- **训练成本较高**：80小时8×H200，但文中未详细对比训练效率与其他方法。
