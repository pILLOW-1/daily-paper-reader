## 摘要
智能体强化学习（Agentic RL）使大语言模型智能体能够从环境奖励中持续改进，然而所得策略并未系统性地积累可跨任务泛化的可复用策略。模块化技能可以提供此类可复用策略，但现有的技能增强型强化学习方法将技能创建与策略优化分离，可能导致采用与演化策略相冲突的技能。受Anthropic的Skill Creator启发，我们提出ReSkill，一种循环强化学习的技能创建框架，使技能演化与策略学习相协调。ReSkill利用GRPO的组结构，以极小的额外开销自然嵌入三种机制：（1）基于断言的技能创建器，从过往经验中诊断失败并提出带触发条件的、基于修正的技能修订方案；（2）组内轨迹采样，实现对技能版本的受控比较，捕获哪个版本最能支持策略的持续学习；（3）采用自适应折扣的汤普森采样，随着策略演化在技能版本选择中平衡探索与利用。在多个领域，ReSkill持续优于现有基于记忆和技能的强化学习方法，在未见任务上提升最大。对技能生命周期的分析表明，随着策略改进，技能被自动创建、测试、改进和裁剪，展示了技能与策略的协调共演化。

## Abstract
Agentic reinforcement learning (RL) enables LLM agents to improve continuously from environment rewards, yet the resulting policies do not systematically accumulate reusable strategies that generalize across tasks. Modular skills can provide such reusable strategies, yet existing skill-augmented RL methods decouple skill creation from policy optimization, risking adopting skills that conflict with the evolving policy. Inspired by Anthropic's Skill Creator, we introduce ReSkill, an RL-in-the-loop skill creation framework that reconciles skill evolution with policy learning. ReSkill exploits the group-wise structure of GRPO to naturally embed three mechanisms with only marginal additional overhead: (1) an assertion-driven skill creator that diagnoses failures from past experience and proposes conditional, trigger-based skill revisions; (2) within-group rollout sampling that enables controlled comparison of skill versions, capturing which version best supports the policy's ongoing learning; and (3) Thompson Sampling with adaptive discounting to balance exploration and exploitation in skill version selection as the policy evolves. Across several domains, ReSkill consistently outperforms existing memory and skill-based RL methods, with the largest gains on unseen tasks. Analysis of the skill lifecycle shows skills being automatically created, tested, refined, and pruned as the policy improves, demonstrating reconciled skill-policy co-evolution.

## 2. 方法论

### 核心思想
利用 GRPO 每步对同一任务采样一组轨迹（G个）的自然结构，在该组内为不同 rollout 分配不同技能版本（新/旧），从而在不增加额外 rollout 的前提下，实现对技能版本的受控比较与评估，并将技能创建循环嵌入 RL 训练过程。

### 关键技术细节

1. **组内采样与三用轨迹（Within-Group Skill Testing）**  
   - 每个训练步，对同一任务 q 采样 G 个轨迹，每个轨迹分配技能版本 vi（通过 Thompson Sampling 决定），生成对应技能库 S_vi 下的轨迹。  
   - 每个轨迹同时服务三个目的：  
     (i) 提供 GRPO 梯度用于策略优化；  
     (ii) 加入经验池 R 用于后续技能诊断；  
     (iii) 更新对应技能版本的 Thompson Sampling 后验。  

2. **RL-in-the-loop 技能创建**  
   - **经验池**：持续收集带技能版本标签和奖励的轨迹对（成功/失败）。  
   - **条件技能加载**：每个技能包含内容 c_k 和触发条件 trig_k（general/beginning/action-pattern 三类），仅当触发条件满足时技能才注入上下文。  
   - **断言驱动的失败诊断**：维护动态断言集 A（规则化谓词），对所有轨迹计算通过率，结合 LLM 分析器产生流行度排序的失败诊断，并更新断言集。  
   - **历史感知的技能修订**：根据当前技能库、失败诊断和之前提议的接受/拒绝历史，技能创建 agent 生成候选新版本 S_new（包含 ADD/MODIFY/DELETE 操作），需通过触发率验证。  

3. **自适应汤普森采样（Thompson Sampling with Adaptive Discounting）**  
   - 将旧版技能和新版技能视为两只臂，用 Beta(α,β) 建模成功概率。  
   - 每步根据后验估计 π(new) = Clip(Pr(p_new > p_old), ε_ts, 1-ε_ts)，按此概率为每个 rollout 分配版本（公式 3）。  
   - **自适应折扣**：为适应策略漂移，后验更新时对历史计数进行折扣：α_v ← w_t·α_v + m_t, w_t = 1/(1+n_t/M)，其中 n_t 为当前步该臂观察数，M 为记忆参数，通过已完成测试周期的预测似然最大化自动估计（无需手动调参）。  
   - **接受/拒绝决策**：每个演化周期结束时，比较新旧版本的后验期望，若 E[p_new] > E[p_old] 则接受新版本，否则回退旧版本。

### 算法流程（Algorithm 1）
1. 初始化策略 πθ₀、技能库 S=∅、经验池 R=∅。
2. 每训练步 t：
   - 采样任务 q，根据 Thompson Sampling 为 G 个 rollout 分配版本 vi。
   - 生成轨迹并计算奖励，更新策略（式 2）。
   - 将轨迹加入 R，更新后验（式 4）。
   - 每隔 Ke 步触发技能演化：基于经验池诊断并生成新候选 S_new，重置后验开始新测试周期。

## 7. 优点

- **零额外开销**：利用 GRPO 组结构，无需额外 rollout 即可评估技能版本，高效整合政策优化和技能创造。
- **自适应折扣汤普森采样**：自动平衡对技能版本的探索与利用，同时通过动态折扣适应策略漂移，且记忆参数 M 可基于数据自动估计。
- **条件触发技能加载**：减少上下文长度，防止无关技能干扰，支持细粒度触发（general/beginning/action-pattern）。
- **断言驱动诊断**：通过规则化断言集合对全局轨迹进行量化分析，生成更精准的失败模式洞察，避免仅依赖个例 LLM 分析。
- **实验设计全面**：覆盖多个领域、模型规模，进行系统的消融和敏感性分析，并展示跨域适应等深度分析。
- **可解释性**：技能生命周期分析和案例研究直观展示了技能与策略如何协同演化。

## 8. 不足与局限

1. **演化频率需调参**：演化频率 Ke 对 ALFWorld 较敏感（Ke 过大时性能下降），虽然 Search 较鲁棒，但仍需对每个域进行手动设置（附录 A 提及自适应调度为未来方向）。
2. **技能调用方式限制**：当前基于 trigger 的条件加载将技能被动注入上下文，而非显式工具调用，可能降低模型对技能应用的控制能力，导致误用（如小模型将技能名当作动作执行）。
