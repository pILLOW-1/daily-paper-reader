## 摘要
推荐算法的迭代正从手工的、依赖工程师的过程向工业化的研究循环转变，但这一转变仍受到结构性执行瓶颈的阻碍：从想法到上线的周期仍依赖人类工程师来生成假设、修改生产代码、启动A/B实验并归因在线结果。因此，创新只能与人员数量线性增长，而非随着证据、计算资源和累积实验知识而复合增长。我们提出AgentX，一个生产环境中部署的多智能体系统，从根本上重构了这一生产函数。AgentX作为一个自演化开发引擎运行：它以任何手动工作流无法持续的规模和速度，自主生成、实施、评估并从推荐实验中学习。该系统在一个闭环中编排四个紧密耦合的阶段。头脑风暴智能体综合来自历史实验、系统架构、数据分析及外部研究的证据，形成排序的、可执行的提案。开发智能体通过基于仓库的生成和多维可靠性验证，将每个提案转化为生产就绪的代码。评估智能体通过有护栏否决权的A/B判断进行安全在线部署，将成功和失败都转化为结构化知识资产。然后，马具演化层(SGPO)将执行轨迹提炼为语义梯度更新，持续优化智能体本身——使系统不仅自动化，而且能够自我改进。

## Abstract
Recommendation algorithm iteration is moving from an artisanal, engineer-bound process toward an industrialized research loop, but this transition remains blocked by a structural execution bottleneck: the idea-to-launch cycle still depends on human engineers to generate hypotheses, modify production code, launch A/B experiments, and attribute online results. Innovation therefore scales linearly with headcount rather than compounding with evidence, compute, and accumulated experimental knowledge. We present AgentX, a production-deployed multi-agent system that fundamentally restructures this production function. AgentX operates as a self-evolving development engine: it autonomously generates, implements, evaluates, and learns from recommendation experiments at a scale and pace that no manual workflow can sustain.   The system orchestrates four tightly coupled stages in a closed loop. A Brainstorm Agent synthesizes evidence from historical experiments, system architecture, data analysis, and external research into ranked, executable proposals. A Developing Agent translates each proposal into production-ready code through repository-grounded generation and multi-dimensional reliability verification. An Evaluation Agent conducts safe online rollout with guardrail-vetoed A/B judgment, converting both successes and failures into structured knowledge assets. A Harness Evolution layer (SGPO) then distills execution trajectories into semantic-gradient updates that continuously sharpen the agents themselves -- making the system not merely automated, but self-improving.

## 2. 方法论

### 2.1 核心思想
AgentX将推荐系统的迭代流程组织为一个闭环，包含四个紧密耦合的阶段：
1. **头脑风暴智能体（Brainstorm Agent）**：将模糊的用户意图转化为有证据支撑的、可执行的实验提案。
2. **开发智能体（Developing Agent）**：将批准提案转化为生产就绪的代码，并经过多维验证。
3. **评估智能体（Evaluation Agent）**：负责安全上线部署、A/B实验判断、以及结果资产化。
4. **马具演化层（Harness Evolution）**：通过语义梯度提示优化（SGPO）将执行轨迹转化为对智能体指令、验证规则、输出合约的增量更新，使系统自我进化。

### 2.2 关键技术细节

- **头脑风暴智能体**：通过**边界设定**和**证据加权提案生成**（公式4）来产生少量高质量候选。证据源包括实验知识库（Experiment KB）、系统知识库（System KB）、数据分析（Data Analysis）和研究论文知识库（Model Research）。每个候选根据目标对齐度、业务有效性、实现可行性等维度打分，最终通过人类审核后交予开发智能体。
- **开发智能体（在线策略轨道）**：采用**仓库基础生成**和**验证导向实现循环**，通过8维质量评分（表1）确保代码可靠性。关键特征：特征字段必须通过schema查询工具验证，DSL调用必须通过编译器检查，禁止属性幻觉。
- **开发智能体（模型研究轨道）**：采用**可证伪归因**（Falsifiable attribution）方法——策略声明因果链和预期可观测值，代码验证匹配后，由独立专家面板投票（超2/3多数），指标由确定性Python代码提取（避免LLM幻觉），最终归因判断CLEAR或UNCLEAR。失败后重试最多3次。
- **评估智能体**：安全部署通过OpenAPI网关，A/B判断采用CUPED/差分之差等方差缩减方法，并设**护栏否决**（guardrail veto），但护栏是业务范围化的、基于复合经济交换指标的、且作为注意力信号而非绝对阻断。负面结果资产化：记录失败原因并索引，防止未来重复。
- **马具演化（SGPO-I和SGPO-II）**：SGPO-I利用会话轨迹计算语义梯度（自然语言诊断），然后通过精炼智能体修改目标子智能体的指令/规则/输出合约，并通过配对回放（paired replay）验证效果后才接纳。SGPO-II基于历史代码合并请求（MR）进行类似优化，评估指标包括语义正确性（40%）、需求覆盖（25%）、文件覆盖（20%）、安全默认（10%）、代码风格（5%）。论文展示了头脑风暴子智能体5轮演化的细节（表2，评分从75.15%提升至98.00%）以及开发智能体异步模块案例（表4，评分从2.60提升至4.90）。
- **模型研究探索循环**：采用三阶段枚举→四阶段探索（复现→模块消融→跨论文组合），并通过记忆引导剪枝（论文级、模块级）和饱和检测（SHA-1哈希重复率>80%时终止）来收缩搜索空间。经验飞轮（Experience flywheel）通过门槛门控和对抗性审查确保知识可靠性。
