## 摘要
大型语言模型（LLM）代理越来越依赖可重用的外部技能来解决长周期交互任务。现有的无训练技能自适应流程通常从完整轨迹或会话级反馈中更新技能，导致故障归因粗糙，往往产生不稳定或过于宽泛的修订。我们提出SkillAdaptor，一种具有显式故障归因的无训练步骤级技能自适应框架，可嵌入OpenClaw类代理控制系统中。给定失败轨迹，SkillAdaptor识别第一个可操作故障步骤，将责任关联到候选技能，并在显式接受检查下应用针对性更新，同时保持骨干网络冻结。我们在WebShop、PinchBench和Claw-Eval上使用Kimi-K2.5、GLM-5和GPT-5.2进行评估。SkillAdaptor在所有三个测试套件上均优于无技能和技能自适应基线，最大单项指标提升分别为：PinchBench平均得分率+1.5个百分点、Claw-Eval平均得分+1.8、WebShop成功率+1.7。这些结果表明步骤级归因支持更稳定且可审计的无训练技能维护\footnote{代码将在https://github.com/zjunlp/SkillAdaptor发布。}。

## Abstract
Large language model (LLM) agents increasingly rely on reusable external skills to solve long-horizon interactive tasks. Existing training-free skill adaptation pipelines usually update skills from full trajectories or session-level feedback, which makes failure attribution coarse and often produces unstable or overly broad revisions. We propose SkillAdaptor, a training-free step-level skill adaptation framework with explicit failure attribution, and it can plug into OpenClaw-class agent harnesses. Given a failed trajectory, SkillAdaptor identifies a first actionable fault step, links responsibility to candidate skills, and applies targeted updates under explicit acceptance checks while keeping the backbone frozen. We evaluate on WebShop, PinchBench, and Claw-Eval with Kimi-K2.5, GLM-5, and GPT-5.2. SkillAdaptor improves over no-skill and skill-adaptation baselines on all three suites, with the largest single-metric improvements of +1.5 points on PinchBench Avg Score%, +1.8 on Claw-Eval Avg Score, and +1.7 on WebShop success rate. These results indicate that step-level attribution supports more stable and auditable training-free skill maintenance\footnote{The code will be released at https://github.com/zjunlp/SkillAdaptor.}.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大型语言模型（LLM）代理在长周期交互任务（如网页购物、代码操作、工具调用）中越来越依赖可重用的外部技能。为了持续改进而无需重新训练基模型，现有工作使用“无训练技能自适应”方法，从执行轨迹中提取或更新技能。
- **现有不足**：当前方法通常基于完整轨迹或会话级反馈进行技能更新（如A-Mem、ExpeL、EvoSkill等），但这种方法存在**粗粒度故障归因**问题：一条失败轨迹中往往包含大量正确的中间步骤，实际失败仅由少数几步导致。若以最终结果驱动更新，失败信号会扩散到无关步骤和技能上，导致修订过于宽泛或不稳定，甚至引入有害技能。
- **核心动机**：提出一种**步级（step-level）故障归因**的技能自适应方法，实现更精准、稳定、可审计的无训练技能维护。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **SkillAdaptor**：一种无训练、模块化的步级技能自适应框架，可插入OpenClaw类代理系统。在失败轨迹中，首先**定位第一个可操作故障步骤**，然后**将该步骤的责任关联到具体候选技能**，最后仅对相关技能进行**定向更新**（修改或生成新技能），并经过显式的**接受性检查（Qualifier gate）** 后才提交到技能库。

### 关键技术细节
- **技能集合**：维护一个文本技能库 `K = {s1, s2, ..., sn}`，每个技能具有标题、原则、适用条件等结构化字段。基模型冻结，仅更新 `K`。
- **技能注入**：执行前，使用Qwen3-Embedding-8B对任务描述和技能进行编码，通过余弦相似度检索top-k候选，再由骨干LLM重排序，选择最相关技能注入提示。
- **自适应阶段（三个步骤）**：
  1. **归因（Attribution）**：
     - **Localizer**：从失败轨迹中预测最早的可归责故障步骤 `t*`，并生成故障行为描述和改进建议 `π`。
     - **Linker**：将故障步骤链接到已检索技能的责任权重 `{(sj, wj)}`，并决定执行**修正（REVISE）** 还是**生成（GENERATE）**。
  2. **修改（Modification）**：
     - 若 `REVISE`：修改权重最高的技能并替换；若 `GENERATE`：从故障上下文合成新技能并追加（通过相似度阈值 `θdup=0.95` 去重）。
  3. **资历（Qualification）**：
     - 重新执行部分任务，比较使用新候选集合 `K+` 与当前集合 `K` 的反馈指标 `M()`，仅当 `Δ ≥ 0` 时才接受更新，否则丢弃。此步抑制有害更新，稳定长期自适应。
- **迭代**：最多10轮，连续3轮无变化则提前停止。

## 6. 主要结论与发现

- **稳定提升**：SkillAdaptor在所有三个基准上均优于无技能基线和所有现有技能自适应基线，最大单项提升：PinchBench平均得分率+1.5、Claw-Eval平均得分+1.8、WebShop成功率+1.7个百分点。

- **效率提升**：虽然输入tokens略有增加，但交互步骤数在PinchBench和Claw-Eval上下降，表明技能注入将部分决策负担从环境交互转移至上下文推理。
- **适用场景**：最有效于失败信号可定位、轨迹暴露中间结构的任务（如数据和代码任务）；在依赖持久状态、外部知识或跨会话上下文的场景（如研究、记忆、安全任务）提升较小。
