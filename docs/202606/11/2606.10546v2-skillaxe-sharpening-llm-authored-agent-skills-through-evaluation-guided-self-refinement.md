## 摘要
技能文档作为指导大型语言模型（LLM）智能体的结构化自然语言指令，对现代智能体框架至关重要，然而LLM难以编写出实际可用的技能。在SkillsBench上，人类编写的技能将通过率提高了16.2个百分点，而LLM编写的技能则没有带来可衡量的提升。我们提出了SkillAxe，一个完全无监督的框架，使LLM能够迭代地诊断和优化自身技能。SkillAxe将技能质量分解为四个可解释维度（质量影响、触发精度、指令合规与故障归因、解决方案路径覆盖），生成无需真实标签、测试套件或环境奖励的结构化改进简报。在SkillsBench上，SkillAxe相对于未改进的LLM技能将通过率相对提高了28%，并将与人类编写技能的差距缩小了47%到67%。我们在SpreadsheetBench上验证了该方法作为持续改进引擎的效果，其中SkillAxe构建的技能库从过去的智能体轨迹中学习，仅用22个技能就将通过率从16.0%提高到52.0%。

## Abstract
Skill documents, structured natural-language instructions that guide Large Language Model (LLM) agents, are critical to modern agent frameworks, yet LLMs struggle to write skills that actually work. On SkillsBench, human-authored skills improve pass rates by 16.2 percentage points, while LLM-authored skills provide no measurable gain. We introduce SkillAxe, a fully unsupervised framework that enables LLMs to iteratively diagnose and refine their own skills. SkillAxe decomposes skill quality into four interpretable dimensions (quality impact, trigger precision, instruction compliance with fault attribution, and solution-path coverage), producing structured improvement briefs that require no ground-truth labels, test suites, or environment rewards. On SkillsBench, SkillAxe improves pass rates by 28\% relative over unimproved LLM skills and closes 47--67\% of the gap to human-authored skills. We validate the approach as a continuous improvement engine in the wild on SpreadsheetBench, where a SkillAxe-built skill library learns from past agent trajectories and raises pass rate from 16.0\% to 52.0\% using only 22 skills.

#### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）驱动的智能体（Agent）严重依赖“技能文档”（Skill Documents）来指导其行为。然而，LLM自身编写的技能文档虽然语法通顺、内容看似合理，但其实际效果远不如人类专家编写的技能。在SkillsBench基准测试中，人类编写的技能能将智能体的通过率提高16.2个百分点，而LLM编写的技能则几乎没有带来任何可衡量的提升。
- **根本原因**：当前缺乏一种系统性的、可操作的诊断反馈机制。技能失败的原因往往是模块化、系统性的（例如，技能在错误的场景下被触发、指令冲突或模糊、提供误导性建议等），但现有的评估方法仅提供粗粒度的“任务通过/失败”信号，无法定位具体问题，导致技能改进只能依赖“试错”和手动调试。
- **研究动机**：旨在开发一种完全无监督的自动化框架，使LLM能够像人类工程师一样，通过分析自身行为来诊断、定位并修正自己编写的技能文档中的问题，从而缩小与人类专家在技能编写方面的巨大差距。

#### 2. 方法论：SkillAxe框架

- **核心思想**：SkillAxe是一个“评估引导的自我精炼”框架。其核心是通过对比一个智能体在“有技能”和“无技能”两种情况下执行相同任务时的行为差异，自动生成结构化的“改进简报”，然后用这个简报引导LLM重写技能文档。
- **关键技术细节与流程**：
    - **四维度诊断**：该框架将技能质量解构为四个可解释的、互补的诊断维度，每个维度捕捉技能生命周期中的一个特定失败模式：
        1.  **质量影响**：技能是否真正帮助了智能体？通过成对比较智能体在有无技能时的输出，评估技能的边际贡献（方向和幅度）。
        2.  **触发精度**：技能是否在正确的任务上被激活？通过分析技能的正向（应激活）和负向（不应激活）触发短语的语义嵌入空间，评估其覆盖广度、负向特异性以及决策边界的清晰度。
        3.  **指令合规与故障归因**：智能体遵循技能指令的情况如何？失败是源于技能本身的不完善还是智能体的执行错误？该方法先将技能分解为可评估的规则，然后对每条规则评估其相关性、智能体遵循度、规则本身质量以及故障归属度，从而区分“需要修复的规则”和“被错误执行的好规则”。
        4.  **解决方案路径覆盖**：技能是否支持智能体能采取的各种有效策略？通过枚举任务的多种可行解决路径，并衡量技能描述与这些路径的语义对齐程度，以评估技能的通用性和鲁棒性。
    - **算法流程**：
        - **阶段1：执行**：对于每个技能，让智能体对同一任务分别执行“无技能”和“注入技能”两次操作，得到输出。
        - **阶段2：诊断**：基于两次执行的结果，通过四个维度计算诊断指标，并汇总成一份结构化的“改进简报”。
        - **阶段3：重写**：LLM根据改进简报对原始技能进行迭代重写。
        - **阶段4：收敛**：重复以上过程，直到技能表现收敛或达到预设的迭代次数。

#### 7. 优点

- **完全无监督**：不需要人工标注、预定义的测试套件或环境特定的奖励函数，使其易于部署到各种新的域和环境中。

- **多维度故障定位**：区分了方法（技能本身的问题）与执行（智能体的问题），避免了因修复正确规则而导致的技能退化。
- **通用的框架**：方法不依赖于特定的LLM或环境，具有很高的可迁移性。
- **持续学习闭环**：设计初衷即是作为生产系统中持续改进的飞轮，利用每一次失败来优化未来的成功。

#### 8. 不足与局限

- **无法检测结构性策略错误**：如果技能本身传授的策略在根本上是错误的，但由于内部逻辑自洽而难以被规则级分析捕获，SkillAxe可能无法诊断。

- **没有解决“搜索空间”问题**：方法论侧重于改进已有的技能，但技能的初始创建仍由LLM的生成能力决定。
