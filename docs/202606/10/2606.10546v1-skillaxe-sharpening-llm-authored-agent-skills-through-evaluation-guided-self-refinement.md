## 摘要
技能文档（即指导大型语言模型（LLM）智能体的结构化自然语言指令）对现代智能体框架至关重要，但LLM难以编写出实际有效的技能。在SkillsBench上，人类撰写的技能将通过率提高了16.2个百分点，而LLM撰写的技能则无显著增益。我们提出SkillAxe，一个完全无监督的框架，使LLM能够迭代诊断并完善自身技能。SkillAxe将技能质量分解为四个可解释维度（质量影响、触发精度、带故障归因的指令合规性以及解决方案路径覆盖率），生成无需真实标签、测试套件或环境奖励的结构化改进摘要。在SkillsBench上，SkillAxe将未经改进的LLM技能的相对通过率提高了28%，并缩小了与人类撰写技能之间47%–67%的差距。我们在SpreadsheetBench上验证了该方法作为持续改进引擎的实际效果，在该基准上，SkillAxe构建的技能库从过往智能体轨迹中学习，仅用22个技能就将通过率从16.0%提升至52.0%。

## Abstract
Skill documents, structured natural-language instructions that guide Large Language Model (LLM) agents, are critical to modern agent frameworks, yet LLMs struggle to write skills that actually work. On SkillsBench, human-authored skills improve pass rates by 16.2 percentage points, while LLM-authored skills provide no measurable gain. We introduce SkillAxe, a fully unsupervised framework that enables LLMs to iteratively diagnose and refine their own skills. SkillAxe decomposes skill quality into four interpretable dimensions (quality impact, trigger precision, instruction compliance with fault attribution, and solution-path coverage), producing structured improvement briefs that require no ground-truth labels, test suites, or environment rewards. On SkillsBench, SkillAxe improves pass rates by 28\% relative over unimproved LLM skills and closes 47--67\% of the gap to human-authored skills. We validate the approach as a continuous improvement engine in the wild on SpreadsheetBench, where a SkillAxe-built skill library learns from past agent trajectories and raises pass rate from 16.0\% to 52.0\% using only 22 skills.

### 2. 方法论：核心思想、关键技术细节
- **核心思想**：SkillAxe是一个完全无监督的框架，将技能质量分解为四个可解释的维度，并通过对比智能体在有/无当前技能时的行为差异来提取诊断信号。
- **四个诊断维度**：
    1. **质量影响（Quality Impact）**：通过配对比较（有技能 vs 无技能）确定技能是正面还是负面影响，并估计改进幅度（方向×幅度，取值[-1,1]）。
    2. **触发精度（Trigger Precision）**：评估技能是否在正确任务上激活。提取正触发短语和负触发短语，用上下文感知嵌入计算覆盖广度、负特异性、边界尖锐度三个几何指标。
    3. **指令合规性与故障归因（Instruction Compliance with Fault Attribution）**：将技能拆解为可评估的规则（提取自技能文档本身），分别评价规则的遵循度、规则质量、以及故障是由技能缺陷还是代理执行错误导致的。计算合规性得分和技能信用得分，从而区分“技能写错了”和“代理没执行好”。
    4. **解决方案路径覆盖（Solution-Path Coverage）**：枚举任务可能的多个解决策略，衡量技能文档是否覆盖了这些策略（用嵌入相似度计算）。
- **流程**：Agent在每个任务上运行有/无当前技能（Phase 1）→ 四个指标诊断（Phase 2）→ LLM裁判根据生成的改进摘要重写技能（Phase 3）→ 迭代直至收敛（Phase 4）。整个过程无需真实标签、手工奖励函数或测试套件。

- **SkillsBench**：

### 7. 优点
- **完全无监督**：不需要任务标签、测试套件或环境奖励，仅依赖任务指令和agent输出。

- **故障归因分离**：区分“技能写错了”和“代理没执行好”，避免错误地改写正确规则。
- **持续学习能力**：适用于生产环境，能从历史轨迹中自动积累和改进技能库。
- **效率高**：在SpreadsheetBench上以更少的技能（22 vs 69）达到相同准确率，降低token成本和延迟。
