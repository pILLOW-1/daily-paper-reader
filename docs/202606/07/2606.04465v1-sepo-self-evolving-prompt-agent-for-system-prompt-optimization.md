## 摘要
系统提示优化可以在不修改底层模型的情况下改善智能体行为，生成人类可读、模型无关的指令。现有方法构建一个提示智能体来优化任务智能体的系统提示，但提示智能体自身的系统提示仍由人工设计且固定不变。我们提出自我进化提示优化（SePO），它将提示智能体自身的系统提示与任务智能体的系统提示一同视为优化目标。SePO采用自指涉设计：单个提示智能体在开放式进化搜索中同时改进任务智能体的系统提示和自身的系统提示，并维护一个候选提示存档作为垫脚石。训练分为两个阶段：预训练阶段在多任务池上进化提示智能体，微调阶段将其应用于目标任务。在涵盖数学（AIME'25）、抽象推理（ARC-AGI-1）、研究生级别科学（GPQA）、代码生成（MBPP）和逻辑谜题（数独）的五个基准测试中，SePO consistently优于Manual-CoT、TextGrad和MetaSPO，与Manual-CoT相比平均准确率提升4.49个百分点。预训练中的提示优化技能还能泛化到预训练混合任务之外的任务，而非记忆每个任务的提示。

## Abstract
System prompt optimization improves agent behavior without modifying the underlying model, yielding human-readable, model-agnostic instructions. Existing methods build a prompt agent that refines task agents' system prompts, yet leave the prompt agent's own system prompt hand-engineered and fixed. We propose Self-Evolving Prompt Optimization (SePO), which treats the prompt agent's own system prompt as an optimization target alongside task agents' system prompts. SePO adopts a self-referential design. A single prompt agent improves both task agents' system prompts and its own under an open-ended evolutionary search that maintains an archive of candidate prompts as stepping stones. Training proceeds in two stages: pre-training evolves the prompt agent on a multi-task pool, and fine-tuning then applies it to a target task. Across five benchmarks spanning math (AIME'25), abstract reasoning (ARC-AGI-1), graduate-level science (GPQA), code generation (MBPP), and logic puzzles (Sudoku), SePO consistently outperforms Manual-CoT, TextGrad, and MetaSPO, improving the average accuracy by 4.49 points compared to Manual-CoT. The prompt optimization skill from pre-training also generalizes to tasks beyond the pre-training mixture, rather than memorizing per-task prompts.

# SePO: Self-Evolving Prompt Agent for System Prompt Optimization 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有系统提示优化方法（如 TextGrad、MetaSPO、PromptBreeder）构建一个专门的“提示智能体”（prompt agent）来优化“任务智能体”（task agent）的系统提示，但提示智能体自身的系统提示仍由人工设计且固定不变。这导致优化能力受限于人类经验，无法在实践中持续积累和提升。
- **背景**：系统提示优化能在不修改模型权重、工具或工作流的前提下改善智能体行为，生成可解释、模型无关的指令。然而，优化过程本身缺少自我改进机制，制约了性能上限。
- **整体含义**：SePO 提出将提示智能体自身也作为优化目标，实现“自我进化”的闭环，使提示优化技能可以从多任务训练中积累并泛化到新任务。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **自指涉设计（Self-Referential Design）**：将提示智能体视为一个特殊的任务智能体，其任务就是优化其他任务智能体的系统提示。同一套搜索过程同时更新任务智能体的系统提示和提示智能体自身的系统提示。
- **两阶段训练管道**：模仿预训练+微调范式。预训练阶段在多任务池上进化提示智能体自身提示；微调阶段固定预训练获得的提示智能体，用于优化目标任务的系统提示。

### 关键技术细节
- **开放式进化搜索**：受 Zhang et al. (2026) 启发，维护一个候选提示存档（archive）。每代从存档中按软最大概率采样父代，生成子代（通过提示智能体根据评估反馈提出改进），子代若优于父代则加入存档。存档作为垫脚石，允许早期提示为后续优化铺路。
- **父代选择**：使用经过温度和子代计数惩罚的 softmax，平衡利用与探索，优先选择较少被采样过的候选。
- **评分与准入**：子代评分基于与父代在相同评估批次上的准确率增量；若子代分数不低于父代（考虑噪声容限），则加入存档（keep_better 策略）。
- **两阶段训练**：
  - **预训练**：种子提示 `p̃⁽⁰⁾`（手工编写），在多任务池 `T̃` 上运行开放进化搜索，得到最优提示 `p̃*`。该过程自指涉：父代即提示智能体自身的提示，子代改进的是自身副本。
  - **微调**：固定 `p̃*` 作为提示智能体的系统提示，对目标任务的任务系统提示 `p` 进行同样的进化搜索，得到优化后的 `p*`。
- **SePO 两种配置**：
  - **SePO-Specialist**：预训练仅使用单一目标任务（微调目标任务相同），每任务需单独预训练。
  - **SePO-Generalist（默认）**：预训练使用多任务混合（通过贪心启发式选择），一次预训练可复用于所有微调任务，降低成本并提升泛化。

### 算法流程（文字说明）
1. 初始化存档 `A` 包含种子提示 `p⁽⁰⁾`。
2. 对每一代 `t=1…G`：
   - 并行生成 `K` 个子代：
     - 从存档中按概率采样父代 `p`。
     - 提示智能体（预训练阶段用当前自身提示，微调阶段用 `p̃*`）生成子代 `p'`。
     - 在训练集上评估子代 `p'` 和父代 `p` 的准确率差，若子代优于父代则加入存档。
3. 返回存档中最高分的提示作为 `p*`。

## 6. 主要结论与发现

- SePO（Generalist）在所有五个任务上取得最佳准确率，平均比 Manual-CoT 提高 4.49 个百分点（71.89→76.38），优于 TextGrad（70.39）和 MetaSPO（71.32）。

- **跨任务泛化**：预训练技能可泛化到未见过任务（Sudoku 从 96.95→99.90），即使预训练中包含相关任务时效果更好，但无关任务仍优于 Manual-CoT。
- **模型鲁棒性**：更换基础模型后，SePO 仍然优于 Manual-CoT（平均提升 +2.13 点）。
- **成本效率**：SePO-Generalist 通过单次预训练分摊至多个任务，总成本低于 SePO-Specialist，与 TextGrad 相当。
