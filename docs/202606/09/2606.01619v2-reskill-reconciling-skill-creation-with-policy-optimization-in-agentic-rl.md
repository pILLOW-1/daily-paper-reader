## 摘要
智能体强化学习（Agentic RL）使大语言模型（LLM）智能体能够从环境奖励中持续改进，然而所得策略并未系统性地积累可跨任务泛化的可复用策略。模块化技能可以提供这种可复用策略，但现有的技能增强强化学习方法将技能创建与策略优化解耦，可能导致采用与演进策略相冲突的技能。受Anthropic的Skill Creator启发，我们提出ReSkill，一种循环强化学习的技能创建框架，协调技能演化与策略学习。ReSkill利用GRPO的组级结构，自然嵌入三种机制且仅需少量额外开销：（1）基于断言的技能创建器，从过往经验中诊断失败并提出条件性、触发的技能修订；（2）组内轨迹采样，实现技能版本的可控比较，捕获哪种版本最佳支持策略的持续学习；（3）自适应折扣的汤普森采样，在策略演进过程中平衡技能版本选择的探索与利用。在多个领域，ReSkill始终优于现有基于记忆和技能的强化学习方法，在未见任务上提升最大。对技能生命周期的分析显示，随着策略改进，技能被自动创建、测试、优化和裁剪，展现了协调的技能-策略共同演化。

## Abstract
Agentic reinforcement learning (RL) enables LLM agents to improve continuously from environment rewards, yet the resulting policies do not systematically accumulate reusable strategies that generalize across tasks. Modular skills can provide such reusable strategies, yet existing skill-augmented RL methods decouple skill creation from policy optimization, risking adopting skills that conflict with the evolving policy. Inspired by Anthropic's Skill Creator, we introduce ReSkill, an RL-in-the-loop skill creation framework that reconciles skill evolution with policy learning. ReSkill exploits the group-wise structure of GRPO to naturally embed three mechanisms with only marginal additional overhead: (1) an assertion-driven skill creator that diagnoses failures from past experience and proposes conditional, trigger-based skill revisions; (2) within-group rollout sampling that enables controlled comparison of skill versions, capturing which version best supports the policy's ongoing learning; and (3) Thompson Sampling with adaptive discounting to balance exploration and exploitation in skill version selection as the policy evolves. Across several domains, ReSkill consistently outperforms existing memory and skill-based RL methods, with the largest gains on unseen tasks. Analysis of the skill lifecycle shows skills being automatically created, tested, refined, and pruned as the policy improves, demonstrating reconciled skill-policy co-evolution.

## 2. 方法论

**核心思想**：利用GRPO（Group Relative Policy Optimization）自然的组级结构，将技能创建、测试和选择直接嵌入RL训练循环，使每个rollout同时服务于策略优化、故障诊断和技能版本评估，无需额外rollout预算。

**关键技术细节**：
- **断言驱动的技能创建（Assertion-Driven Skill Creator）**：从训练经验中诊断失败模式，提出条件触发的技能修订。使用经验池（reservoir）收集成功-失败轨迹对，通过动态断言集评估失败模式，基于LLM分析产生故障诊断和技能修订提案。
- **组内采样（Within-Group Rollout Sampling）**：同一GRPO组内的rollout共享相同任务和策略，唯一变量是技能版本。通过将不同技能版本分配给组内不同rollout，实现可控比较。
- **自适应折扣的汤普森采样（Thompson Sampling with Adaptive Discounting）**：将新旧技能版本视为两个臂（arms），用Beta后验建模成功概率。每一步根据后验预测的胜率分配组内rollout，并引入自适应折扣权重 $w_t = 1/(1+n_t/M)$，其中$n_t$是该步分配给该臂的rollout数量，$M$为记忆参数，可通过预测似然最大化在线估计。这允许根据采样频率动态调整旧证据的影响。

**算法流程（文字描述）**：
1. 初始化策略$\pi_{\theta}$、技能库$S$、经验池$R$、Beta后验($\alpha=1,\beta=1$)、记忆参数$M$。
2. 每步训练：
   - 采样任务$q$，计算当前概率$\pi_t(\text{new})$，为组内每个rollout独立分配技能版本$v_i$。
   - 在对应技能库$S_{v_i}$下生成轨迹$\{\tau_i\}$，计算奖励。
   - 使用公式(2)的RESKILL目标更新策略$\theta$（$J_{RESKILL}(\theta)$与标准GRPO类似，但分配版本后计算）。
   - 轨迹加入经验池$R$。
   - 更新后验：$\alpha_v \leftarrow w_t\alpha_v + m_t$, $\beta_v \leftarrow w_t\beta_v + (n_t-m_t)$，其中$w_t = (1+n_t/M)^{-1}$。

## 7. 优点

- **RL循环内技能创建**：将技能评估与策略优化紧密结合，无需额外rollout预算，每个rollout多重职责。
- **组内可控比较**：利用GRPO组结构自然实现技能版本的受控对比，避免独立部署开销。
- **自适应折扣汤普森采样**：平衡探索-利用，并随着策略演化动态折扣旧证据，无需手动调参（M通过数据估计）。
- **断言驱动故障诊断**：规则化断言+LLM分析，比逐轨迹诊断更高效、更有针对性。
- **条件技能加载**：触发条件确保只有相关技能进入上下文，保持长的交互轨迹中上下文紧凑。
- **广泛的实验验证**：覆盖具身、问答、科学、编码、网购等多个领域，在未见任务、难任务上提升更显著。

## 8. 不足与局限

- **演化频率敏感**：性能在演化频率过低时下降（如ALFWorld K_e=20），需要根据训练长度调整。论文建议自适应演化调度作为未来方向。
- **技能调用控制受限**：当前通过触发条件加载，模型通过when_to_use字段判断是否应用，但不够精细。有时模型将技能名称当作可执行动作（元bug），或不加选择地应用技能。论文提出将技能构建为显式工具调用可作为改进方向。
- **技能容量负担**：较小模型有时混淆技能指导与环境动作，或在不适用时过度应用技能，增加了认知负荷。需要训练模型更好地区分推理时指导和行动时指令。
