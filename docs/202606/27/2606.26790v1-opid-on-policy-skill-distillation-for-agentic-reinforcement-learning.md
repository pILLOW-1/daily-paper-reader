## 摘要
基于结果的强化学习为语言智能体提供了稳定的优化基础，但其稀疏的轨迹级奖励对哪些中间决策应被强化或抑制提供的指导甚少。基于策略的自我蒸馏提供了密集的令牌级监督，然而现有的技能条件变体通常依赖外部技能记忆或检索到的特权上下文，这些方法维护成本高，且在多轮交互中可能与当前策略产生的状态分布不匹配。我们提出OPID（基于策略的技能蒸馏），一个直接从完成的基于策略轨迹中提取技能监督的框架。OPID将轨迹后期经验表示为层级技能：情节级技能捕捉全局工作流或避免失败规则，而步骤级技能在关键时间步捕捉局部决策知识。一种临界优先路由机制在识别出关键决策时使用步骤级技能，否则回退到情节级技能作为默认指导。选中的技能被注入交互历史，使得旧策略能够在原始和技能增强两种上下文中对相同的采样响应重新评分。由此产生的对数概率偏移提供了令牌级的自我蒸馏优势，并与结果优势结合用于策略优化。因此，OPID保留了强化学习作为主要训练目标，同时引入了密集且分布匹配的后期经验监督。在ALFWorld、WebShop和基于搜索的问答上的实验表明，OPID在智能体性能、样本效率和鲁棒性上普遍优于仅结果强化学习和现有技能蒸馏基线。我们的代码可在https://github.com/jinyangwu/OPID/tree/main获取。

## Abstract
Outcome-based reinforcement learning provides a stable optimization backbone for language agents, but its sparse trajectory-level rewards provide little guidance on which intermediate decisions should be reinforced or suppressed. On-policy self-distillation offers dense token-level supervision, yet existing skill-conditioned variants often rely on external skill memories or retrieved privileged context, which are costly to maintain and can be mismatched with the state distribution induced by the current policy in multi-turn interaction. We propose \textbf{OPID} (\textbf{O}n-\textbf{P}olicy Sk\textbf{i}ll \textbf{D}istillation), a framework that extracts skill supervision directly from completed on-policy trajectories. OPID represents trajectory hindsight as hierarchical skills: episode-level skills capture global workflows or failure-avoidance rules, while step-level skills capture local decision knowledge at critical timesteps. A critical-first routing mechanism uses step-level skills when critical decisions are identified and falls back to episode-level skills as default guidance otherwise. The selected skill is injected into the interaction history, allowing the old policy to re-score the same sampled response under both original and skill-augmented contexts. The resulting log-probability shift yields a token-level self-distillation advantage, which is combined with the outcome advantage for policy optimization. OPID thus preserves RL as the primary training objective while introducing dense, distribution-matched hindsight supervision. Experiments on ALFWorld, WebShop and Search-based QA demonstrate that OPID generally improves agent performance, sample efficiency, and robustness over outcome-only RL and existing skill-distillation baselines. Our code is available at https://github.com/jinyangwu/OPID/tree/main.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：在基于强化学习的语言智能体训练中，环境奖励通常是稀疏的轨迹级反馈（仅成功/失败），无法告知哪些中间决策导致了最终结果，导致信用分配困难。现有的技能条件蒸馏方法虽然提供密集监督，但依赖外部技能记忆或检索特权上下文，维护成本高且容易与当前策略的状态分布不匹配（尤其是长程交互中状态漂移）。
- **整体含义**：本文提出 OPID，直接从当前策略（on-policy）完成的轨迹中提取层次化后期技能（hierarchical hindsight skills），并利用技能自蒸馏为每个令牌提供密集监督，同时保留结果强化学习作为主要优化目标，从而提高智能体的性能、样本效率和鲁棒性，且推理时无需额外技能检索。

## 2. 方法论
- **核心思想**：将完成的 on-policy 轨迹转化为两个层次的技能——情节级技能（episode-level skill，总结整体工作流或失败规避规则）和步骤级技能（step-level skill，在关键时间步提供局部决策指导）。通过关键优先路由（critical-first routing）选择最合适的技能注入历史，使旧策略在原始和技能增强两种上下文中对同一响应重新评分，生成令牌级自蒸馏优势，并与组相对结果优势结合进行策略优化。
- **关键技术细节**：
  - **On-Policy Skill Extraction**：使用 LLM 分析器（默认 GLM-5.2）处理完整轨迹，输出一个情节级技能和若干关键步骤的技能（关键步骤由分析器识别，数量由超参限制，如 ALFWorld 最多5个）。
  - **Critical-First Skill Routing**：对每个步骤，若处于关键时间步则使用步骤级技能，否则使用情节级技能。两步技能不混合，确保每个步骤得到最合适的粒度。
  - **Skill-Based Self-Distillation**：将路由到的技能注入原始交互历史，形成增强上下文。旧策略在原始和增强上下文中分别对同一响应令牌做对数概率计算，其差值作为技能优势 $A^{\text{skill}}_{\tau,t,\ell}$。正值表示技能使该令牌更可能，负值表示更不可能。
  - **Policy Optimization**：最终优势为 $A^{\text{OPID}} = A^{\text{ep}} + \lambda_{\text{skill}} A^{\text{skill}}$，其中 $A^{\text{ep}}$ 是 GRPO 风格的组相对轨迹奖励优势（对组内轨迹奖励归一化）。使用 PPO 裁剪目标 $\mathcal{L}_{\text{policy}}(\theta) = -\mathbb{E}\left[ \min(\rho A^{\text{OPID}}, \text{clip}(\rho,1-\epsilon,1+\epsilon)A^{\text{OPID}}) \right] + \beta \mathcal{L}_{\text{KL}}$ 进行优化。
- **训练-推理分离**：分析器、路由和技能评分仅在训练构建优势时使用，推理时策略仅依赖普通交互历史，无额外代价。

## 6. 主要结论与发现
- **OPID 一致提升结果RL**：在多数模型-领域组合中，OPID 优于 GRPO，例如 Qwen2.5-3B 在 ALFWorld 上提升 +9.3 点，WebShop 提升 +10.9 点；对于小模型 Qwen3-1.7B 提升更大（ALFWorld +12.8，WebShop +26.5）。仅在 Search-based QA 上 Qwen3-1.7B 持平。
- **与强混合方法竞争**：OPID 在多个指标上达到或超越 Skill-SD、SDAR 等基线，尤其在 ALFWorld 和 WebShop 上取得最佳平均成功率。
- **技能内部化**：OPID 的轨迹衍生技能被蒸馏进策略参数，推理时无需技能提示。相比之下，Skill-GRPO（训练时使用技能但测试时移除）性能大幅下降，表明技能未被内化。
- **样本效率与泛化**：OPID 在数据减少时仍优于 GRPO（40% 数据即可接近 GRPO 全数据性能），且在 ALFWorld Unseen 上将平均成功率从 70.9% 提升至 78.6%。
- **消融验证**：层次技能和关键优先路由对性能关键，移除任一均导致下降。

## 7. 优点

## 8. 不足与局限
- **对分析器依赖**：技能提取依赖额外的 LLM 分析器（本实验使用 GLM-5.2），分析器质量和参数（如关键步骤数量）可能影响性能，且引入额外训练成本。
- **部分场景未超越基线**：在 Search-based QA 的 Qwen3-1.7B 上，OPID 仅持平 GRPO，未显示提升，说明在简单或短序列任务中优势可能有限。
- **实验覆盖不足**：尽管包含三个领域，但未涉及类似 WebArena、SWE-bench 等更复杂的真实世界交互环境，结果的泛化性有待扩展。此外，仅对 3 种模型规模进行了测试，未探索更大模型如 70B 或 MoE 架构。

- **计算开销**：虽然推理无额外开销，但训练时每个轨迹需要运行分析器两次（提取技能+评分），增加计算成本和延迟，论文未报告具体时间开销。
