## 摘要
设备端语言模型智能体通过检索记忆中的经验累积来改进，而非通过更新权重。这种内存具有硬边界且暴露：它消耗RAM和能量，通过窄上行链路到达对等节点，并因能被智能体读取内容写入而成为攻击面。现有系统各自覆盖该问题的某一部分：智能体记忆无预算增长，设备端方法仅依据成功保留条目，而投毒主要被作为攻击而非内存治理问题研究。我们提出\sys{}，一种基于净每字节值的评分系统，用于管理智能体经验记忆的生命周期。核心思想是让预算作为策展人：每个条目按每字节的值减去危害评分，因此单一标准决定保留、分享和信任的内容。\sys{}做出三项决策：(1) \textbf{KEEP}在RAM和能量预算下驱逐低价值字节；(2) \textbf{SHARE}仅在见解价值超过上行成本时发送；(3) \textbf{TRUST}根据来源对对等节点条目进行门控。在语言模型智能体任务漂移基准测试以及包含两个机械臂节点和一个集线器的真实异构Jetson测试平台上，\sys{}将内存减少$2.7\times$，上行链路减少$2.4\times$，将注入成功率从0.75降至零，并提高受投毒或陈旧内存污染案例的准确率。按净值策展同时减少了占用空间、能量、上行链路和注入成功率，且不降低准确率。在这种设置下，按净值遗忘增强了智能体而非削弱它。

## Abstract
On-device language-model agents improve by accumulating experience in retrieved memory rather than by updating weights. This memory is hard-bounded and exposed: it consumes RAM and energy, reaches peers through a thin uplink, and becomes an attack surface because it is writable by what the agent reads. Existing systems each cover one part of this problem: agentic memories grow without a budget, on-device methods keep entries by success alone, and poisoning is studied mainly as an attack rather than as a memory-governance problem. We propose \sys{}, a single net-value-per-byte score that governs an agent's experience-memory lifecycle. The main idea is to let the budget act as the curator: each entry is scored as value minus harm, per byte, so one ruler decides what to keep, share, and trust. \sys{} makes three decisions: (1) \textbf{KEEP} evicts low-value bytes under the RAM and energy budget; (2) \textbf{SHARE} sends an insight only when its value exceeds its uplink cost; and (3) \textbf{TRUST} gates a peer entry by provenance. On language-model-agent task-drift benchmarks and a real heterogeneous Jetson testbed with two robot-arm nodes and a hub, \sys{} reduces memory by $2.7\times$ and uplink by $2.4\times$, drives injection success from 0.75 to zero, and raises accuracy on cases corrupted by poison or stale memory. Curating by net value reduces footprint, energy, uplink, and injection success together without reducing accuracy. In this setting, forgetting by net value improves the agent rather than weakening it.

## 1. 核心问题与整体含义（研究动机和背景）
设备端语言模型智能体（on-device LLM agent）通过在检索式外部记忆中累积经验来持续改进，而非更新模型权重。然而，这种记忆面临三重边缘约束：
- **资源硬边界**：RAM和能量有限，记忆不能无限增长。
- **暴露的攻击面**：记忆可被智能体读取的任何内容写入，包含来自对等节点的共享条目，因而容易受到记忆投毒攻击。
- **上行链路狭窄**：与对等节点共享经验需要消耗带宽和能量。

现有方法各自仅覆盖部分问题：智能体记忆架构（如A-MEM）增长但不设预算；设备端重放策略仅按成功与否保留条目；记忆投毒主要被作为攻击研究，而非纳入内存治理。**缺乏一种统一机制，能在三个物理预算（内存、能量、上行）下同时决定保留什么、分享什么、信任什么。**

论文提出 **CURATOR**（Continual, bUdget-cuRated Agent-memory neT-value scOre R）—— 一种基于每字节净价值（net value per byte）的评分体系，将预算本身作为“策展人”，一次评分即可治理内存的整个生命周期。

## 2. 方法论

### 核心思想
用一个统一的净价值密度分数 $\rho(m)$ 决定每个经验条目的命运：
\[
\rho(m) = \frac{\hat{V}(m) - \lambda \hat{H}(m)}{b(m)}
\]
- $\hat{V}(m)$：估计价值，由三项乘积组成：检索倾向（propensity）$p$、条件帮助度（helpfulness）$q$、抽象增益（abstraction gain）$a$。
- $\hat{H}(m)$：估计危害，包含负迁移风险 $\eta(m)$ 和来源风险 $\pi(m)$。
- $b(m)$：条目的字节占用。
- $\lambda$：价值与危害的权衡权重。

### 关键技术细节
- **价值估计**：
  - 检索倾向 $p$：基于软max对最近查询向量草图的重现概率。
  - 帮助度 $q$：通过无监督方式（自一致性）估计条目对查询的边际效用，仅在线拟合一个小型头部，无需真值奖励。
  - 抽象增益 $a$：原始轨迹字节与蒸馏后字节的比值。
- **危害估计**：
  - 负迁移风险 $\eta$：基于条目嵌入与当前任务工作中心的马氏距离，惩罚过于特异或过时的条目。
  - 来源风险 $\pi$：逻辑斯蒂门控，基于来源特征（外部/对等/自生成、自我强化次数、与注入指令的相似度），权重固定，不提供攻击者训练表面。
- **三项决策（算法 1）**：
  1. **KEEP**：按 $\rho$ 降序贪婪填充固态槽，直到预算 $B$ 耗尽；条目在淘汰前先尝试蒸馏以提升密度。
  2. **SHARE**：仅在 $\rho_s(m) > \tau$ 且未重复且未超出上行预算 $L$ 时发送；对等方通过广告一个查询向量草图帮助估计 $V_p$。
  3. **TRUST**：仅 $\rho(m') > \theta$ 才接纳对等条目；来源危害使投毒条目得分低于阈值。
- **能量管理**：使用虚拟队列（drift-plus-penalty）控制时间平均检索能量在预算 $\bar{\varepsilon}$ 内。

## 3. 实验设计

### 数据集/场景
- **任务漂移序列**：基于 ALFWorld、BabyAI 工具环境，以及 MemoryAgentBench 的选择性遗忘和测试时学习轨道。每个序列包含干净任务和“受害子集”（易被陈旧或投毒条目干扰的任务）。

- 无策展（keep-all）、朴素 LRU、recency、A-MEM、Agentic Memory、MaRS 文本移植版、全记忆 oracle（非部署上限）。

### 度量指标
- 任务准确率、受害子集准确率（选择性遗忘，SF）、峰值内存占用、上行链路每轮字节数、注入攻击成功率（ASR）。

## 6. 主要结论与发现
1. **四轴同步提升**：与 keep-all 相比，CURATOR 将峰值内存从 287 KB 降至 107 KB（2.7×），上行链路从 1068 B/round 降至 454 B（2.4×），注入 ASR 从 0.75 降至 0，同时任务准确率从 0.528 升至 0.605，受害子集准确率从 0.294 升至 0.420。
2. **准确率恢复集中在被污染案例**：干净任务准确率不变，受害和投毒子集大幅恢复。重复实验表明，这种恢复来自净价值规则而非单纯缩小内存。
3. **单一评分覆盖全生命周期**：KEEP、SHARE、TRUST 可用同一个 $\rho$ 分数完成，无需三个独立模块。来源风险是安全的唯一保障：去除来源项后 ASR 立即回升至 0.75。
4. **预算帕累托前沿**：准确率在内存预算 107 KB 和上行预算 454 B 附近达到膝盖点，超过此点后准确率才开始下降。
5. **消融证实每个组件不可或缺**：去除抽象增益降低准确率；去除每字节归一化导致体积膨胀；去除危害项同时损害准确率和安全。
6. **硬件跨代一致性**：在 Jetson Orin 和 Thor 上，能量、内存、上行均降至 keep-all 的 38%–64%。
7. **跨代理分享时来源门控抑制交叉投毒**：真实硬件上，使用来源门控的 $\rho$-share 上行带宽仅为广播的 1/3，交叉 ASR 接近零。
8. **结论“遗忘改善智能体”**：由于模型冻结，遗忘低价值条目不损失技能，反而清除负面经验，因此资源节省与安全保护不是代价而是增益。

## 7. 优点
- **统一框架**：用一个评分函数同时解决保留、分享、信任三个本应独立设计的问题，简化了系统设计。
- **资源与安全双赢**：在降低资源消耗的同时消灭了投毒攻击，挑战了“遗忘等于损失能力”的传统直觉。
- **轻量级实现**：仅需轻量在线拟合的帮助度头部，无大规模重训练；几乎所有组件固定，适合边缘设备。
- **真实硬件验证**：在异构 Jetson 平台（两种架构、三个节点）上部署，测量实际能量、内存、带宽。
- **全面消融与灵敏度分析**：清晰展示了每个组件对各个轴的单独贡献，实验设计公平严谨。

## 8. 不足与局限
- **攻击模型局限性**：来源风险采用固定先验函数（logistic 门控），面对能够伪造自生成来源或利用跨会话自我强化的高级攻击，可能仍有曝光风险（论文承认，伪造来源下 ASR 升至 0.30 而非完全归零）。
- **内存类型限制**：CURATOR 仅治理“经验记忆”（规划见解），不覆盖动作策略或低层控制器，因此不适用于需要参数更新的持续学习场景。
- **假设模型冻结**：如果智能体需要更新权重以适应全新技能，该框架无法应对参数级别的灾难性遗忘问题。
- **可扩展性不确定性**：实验最多 8 个智能体组，更大规模的高动态网络（如数百设备）中共享调度和信任决策可能面临新挑战。
- **隐私未作为核心机制**：虽然通过共享只传输查询草图而非原始轨迹来保护隐私，但未讨论隐私预算或差分隐私等更正式的隐私保证。
- **能量管理简化**：能量通过虚拟队列控制，但仅考虑检索和重嵌入步骤；未建模模型推理本身的能量（因模型冻结，推理能耗固定）。
