## 摘要
对于多步交互环境中的LLM智能体，一个关键挑战是如何有效利用积累的交互经验。现有工作通常将这种经验分为两种用途：将其作为自然语言规则保留在模型外部以便后续提示，或使用轨迹和反馈来更新模型参数。前者易于解释但可能与不断演化的策略脱节；后者更广泛地改进策略，但在稀疏奖励设置下对局部错误的修正有限。我们提出了面向LLM智能体的经验规则与策略联合学习（JERP），该方法从相同的交互轨迹中更新长期经验规则池和策略。在决策时，JERP检索与任务相关的规则，并将它们与交互历史一起作为智能体的条件。每轮结束后，它利用收集的轨迹同时优化策略，并通过将当前部署与参考成功轨迹进行比较来修订规则池。这种耦合使得规则池与不断演化的策略保持一致，同时允许稳定有效的行为逐渐内化到模型自身中。在AlfWorld和WebShop上的实验表明，JERP在复杂交互任务的决策性能上取得了持续提升。

## Abstract
For LLM agents in multi-step interactive environments, a key challenge is to make effective use of accumulated interaction experience. Existing work has typically separated two uses of such experience: keeping it outside the model as natural-language rules for later prompting, or using trajectories and feedback to update the model parameters. The former is easy to interpret but can fall out of sync with the evolving policy; the latter improves the policy more broadly but provides only limited correction for local mistakes in sparse-reward settings. We present Joint Learning of Experiential Rules and Policies for LLM Agents (JERP), which updates a long-term experiential-rule pool and the policy from the same interaction trajectories. At decision time, JERP retrieves task-relevant rules and conditions the agent on them together with the interaction history. After each episode, it uses the collected trajectories both to optimize the policy and to revise the rule pool by comparing current rollouts with reference successful trajectories. This coupling keeps the rule pool aligned with the evolving policy while allowing stable and effective behaviors to be gradually absorbed into the model itself. Experiments on AlfWorld and WebShop show that JERP yields consistent gains in decision performance for complex interactive tasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）智能体在多步交互环境中（如网页导航、具身交互）需要有效利用积累的交互经验，但现有方法将经验分离为两种用途：
  - **外部规则**：将经验以自然语言规则形式存储，用于后续提示（如Reflexion、ExpeL）。优点是可解释、可编辑，但规则可能随策略演化而过时或误导。
  - **参数更新**：利用轨迹和反馈直接更新模型参数（如强化学习微调）。能全局改进策略，但在稀疏奖励环境下对局部错误的修正有限。
- **研究动机**：能否将同一批交互数据同时用于规则更新和策略优化，使规则池与演化策略对齐，同时将稳定有效的行为逐渐内化到模型参数中。
- **总体含义**：提出JERP（Joint Learning of Experiential Rules and Policies），实现经验利用的闭环，提升复杂交互任务的决策性能。

## 2. 方法：核心思想、关键技术细节、算法流程

### 核心思想
- 为每个任务实例 `d` 维护一个长期经验规则池 `K(d)`，每条规则包含文本 `z_i` 和效用分数 `s_i`。
- 每个训练epoch：采样任务实例，从规则池中选取得分最高的 `k` 条规则作为工作规则集 `eK(d)`，与交互历史一起作为决策上下文。
- 同一批轨迹（N条）被用于**两个更新**：
  1. **模型参数更新**：基于组相对优势（GRPO风格）优化策略。
  2. **经验规则池更新**：通过对比当前轨迹与参考成功轨迹，生成规则编辑操作（ADD/EDIT/UPVOTE/DOWNVOTE/MERGE），并更新效用分数。

### 关键技术细节
- **轨迹采样**：在每个任务实例上，策略 `π_θ` 结合工作规则集生成N条完整轨迹，每条轨迹获得终止奖励 `R(τ_i)`。
- **参数更新**：
  - 计算组内奖励均值 `μ_d` 和标准差 `σ_d`，定义轨迹级别优势 `A_i = (R(τ_i) - μ_d)/(σ_d + δ)`，轨迹内所有步共享同一优势。
  - 优化目标为GRPO损失：`L_GRPO(θ) = -1/N Σ_i (1/|τ_i|) Σ_t min(ρ_i,t A_i, clip(ρ_i,t, 1-ε, 1+ε) A_i) - β D_KL`，其中 `ρ_i,t = π_θ(a_i,t|x_i,t) / π_θ_old(a_i,t|x_i,t)`。
- **规则池更新**：
  - 输入：当前规则池 `K(d)`、当前轨迹组 `T_d`、参考成功轨迹集 `T^+(d)`（若无可为空）。
  - 使用冻结参数的LLM生成结构化编辑操作：ADD（添加新规则）、EDIT（修订规则文本）、UPVOTE/DOWNVOTE（增减效用分数）、MERGE（合并语义相似规则）。
  - 应用操作后更新各规则分数（ADD初始分 s0；UPVOTE+δ+；DOWNVOTE-δ-；MERGE取最大分），低于阈值则删除规则。同时维护工作规则集大小限制。

### 算法流程（文字描述）
1. 初始化每个任务的规则池 `K(d) ← ∅`，参考成功轨迹集 `T^+(d) ← ∅`。
2. 对每个训练epoch：
   - 采样任务实例 `d`，保存旧策略 `θ_old`。
   - 从 `K(d)` 中选择top-k规则构成工作规则集 `eK(d)`。
   - 交互N轮：每轮初始化为空轨迹，循环至多T步：构建prompt `(d, h_t, eK(d))`，采样动作 `a_t`，执行并获得下一观测，记录轨迹。若终止则退出。
   - 计算每条轨迹的奖励 `R(τ_i)`，加入轨迹组 `T_d`。
   - 计算组相对优势，用GRPO目标更新 `θ`。
   - 调用 `ReflectAndEdit(K(d), T_d, T^+(d))` 生成规则编辑操作，应用更新 `K(d)`。
   - 更新规则分数并修剪超出容量限制的规则。
   - 将当前成功轨迹加入 `T^+(d)`。

- **WebShop**：在线购物交互环境，根据用户需求执行搜索、浏览、比较、购买。

### 评估指标
- AlfWorld：任务成功率（%）。
- WebShop：平均分数和任务成功率（%）。

### 对比方法
- **Vanilla LLM**：直接提示，无推理框架、无记忆、无参数更新。
- **ReAct**：推理与动作交替，仅当前episode上下文。
- **Reflexion**：跨episode的反思记忆，但记忆在模型外。
- **RLOO**：REINFORCE with Leave-One-Out baseline，进行参数更新。
- **GRPO**：组相对策略优化（无值模型），进行参数更新。

## 6. 主要结论与发现

- **总体性能**：JERP在AlfWorld上以61.5%的成功率优于所有基线（GRPO 57.8%，RLOO 48.7%）；在WebShop上平均分数79.0、成功率64.1%，优于GRPO（56.2%）和RLOO（57.8%）。
- **规则池作用**：在更长决策序列和更多中间约束的任务（Clean, Heat, Cool, Pick2）上，JERP的优势更明显，说明规则池能保存有效操作模式。
- **动态更新必要性**：消融实验表明，固定规则池后性能提升放缓，而持续更新规则池能持续吸收新经验，保持高成功率。
- **耦合效果**：规则池与策略同步演化，避免了规则过时，同时加速了稳定行为的内化。
