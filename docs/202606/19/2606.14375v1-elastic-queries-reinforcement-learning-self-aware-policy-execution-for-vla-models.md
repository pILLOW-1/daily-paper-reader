## 摘要
视觉-语言-动作（VLA）模型是机器人操作中强大的动作生成器，但通常以固定的推理和重新规划计划执行。这种刚性忽视了机器人控制难度的不均匀性：富含接触或不确定的状态可能需要更多的计算和更新鲜的反馈，而较简单的状态则通常可以用更少的推理步骤和更长的开环执行来处理。我们提出弹性查询强化学习（EQRL），一个使每个VLA策略查询具有弹性的框架。一种轻量级潜在调度适配器联合选择潜在输入、去噪预算和动作块长度，而无需微调底层的VLA模型。为了使调度具有难度感知能力，EQRL在联合潜在调度动作上训练一个评论家，并从评论家集成的不一致性中推导出状态难度信号。该信号将计算资源引导至困难状态，而学习到的残差允许任务驱动的修正。我们将可变块执行形式化为查询级宏动作强化学习，采用依赖于块的折扣和摊销的函数评估次数（NFE）预算。在仿真和真实机器人操作中，EQRL在保持或提高任务成功率的同时，降低了摊销推理成本。

## Abstract
Vision-language-action (VLA) models are powerful action generators for robot manipulation, but they are typically executed with fixed inference and replanning schedules. This rigidity ignores the uneven difficulty of robot control: contact-rich or uncertain states may need more computation and fresher feedback, while easier states can often be handled with fewer inference steps and longer open-loop execution. We propose Elastic Queries Reinforcement Learning (EQRL), a framework that makes each VLA policy query elastic. A lightweight latent-schedule adaptor jointly selects the latent input, denoising budget, and action chunk length, without fine-tuning the underlying VLA model. To make scheduling difficulty-aware, EQRL trains a critic over the joint latent-schedule action and derives a state difficulty signal from critic ensemble disagreement. This signal guides compute toward difficult states, while a learned residual allows task-driven correction. We formulate variable chunk execution as query-level macro-action RL with chunk-dependent discounting and an amortized number-of-function-evaluations (NFE) budget. Across simulation and real-robot manipulation, EQRL reduces amortized inference cost while preserving or improving task success.

### 论文提出的方法论

- **核心思想**：设计一个轻量级适配器（adaptor），在冻结的VLA模型之上，通过强化学习联合选择每个查询的潜在引导变量（w）、去噪步数（K）和动作块长度（C）。利用评论家（critic）集成的不确定性度量推导出状态难度信号，指导计算分配偏向困难状态，同时学习残差允许任务特定修正。将变长块执行建模为查询级宏动作强化学习，引入块依赖折扣和摊销NFE（函数评估次数）预算。
- **关键技术细节**：
  1. **Latent-Schedule Query Actions**：适配器输出三个随机变量（w, z_K, z_C），其中z_K和z_C为连续变量，通过映射得到关于基础调度（K0, C0）的残差，最终得到连续调度值，再取整用于环境交互。
  2. **Difficulty-Guided Schedule Parameterization**：训练一个由M个Q函数组成的评论家集成，在基础调度处计算集成标准差作为状态难度原始值，归一化后转换为秩信号，再通过tanh得到有符号难度s(o) ∈ [-1,1]。正难度表示需更保守执行（更多去噪步、更短块），负难度相反。基于s(o)生成调度先验K_p(o)和C_p(o)，最终调度为先验加上学习残差（通过门控g_j和残差权重λ_r控制）。
  3. **Query-Level Learning Objective**：每次查询产生宏过渡，折扣因子为γ^(L_j)，其中L_j为实际执行的步数。奖励由任务成功奖励和NFE预算项构成。使用SAC风格优化演员-评论家，其中演员最大化熵正则化Q值，评论家最小化均方贝尔曼误差。
  4. **补充正则化**：对齐损失促使调度分配a_alloc与难度信号s同号；全局NFE带（band）约束整个episode的摊销NFE，超预算惩罚，低于下限也可能惩罚（鼓励在带内）。
- **算法流程**（文字说明）：
  1. 固定VLA模型参数。
  2. 初始化适配器（演员和评论家集成）、基础调度参数。
  3. 在每个时间步j，观察状态o，演员网络根据o输出w、z_K、z_C。
  4. 计算难度信号s(o)（基于评论家集成在基础调度处的标准差）。

  6. 使用冻结VLA，输入o、w和K_j，生成动作块，执行前C_j个动作，观察奖励和下一状态。

### 论文的主要结论与发现

1. **弹性调度有效降低推理成本**：在LIBERO-4Tasks上，EQRL相比DSRL降低了24.3%的相对NFE，同时最终成功率提升1%（0.95→0.96），成功率AUC提升4%（0.86→0.90）。在ALOHA-Cube上，NFE降低20%，最终成功率从94%提升至100%。
2. **真实机器人同样有效**：离线4个任务平均成功率从81.3%提升至83.8%，平均NFE降低32.4%，平均执行时间缩短16.1%。在线真实任务成功率从90%提升至95%，NFE降低31.8%。
3. **难度感知是关键**：消融实验表明，仅降低NFE（matched-NFE DSRL）或仅调整去噪步/块长度之一，均无法达到EQRL的性能，证明联合学习调度和难度引导非常重要。
4. **VLA执行是状态依赖的资源分配问题**：EQRL通过强化学习自动分配计算资源，在简单状态使用少步长和长块，困难状态使用多步长和短块，从而在不牺牲成功率的情况下大幅提升效率。
