## 摘要
当前的自主机器人系统能够编写可执行的代码即策略程序、观察反馈并在多次尝试中修正行为，但它们仍然主要是任务驱动的：只有在明确指令后才能获得可复用的技能。我们研究了趣味性自主机器人学习，其中具身编码智能体在下游任务到来之前，将自主探索作为持续的技能学习阶段。我们引入了RATs（机器人智能体团队），专为游戏时间技能获取而设计。在探索过程中，RATs提出新颖但可学习的探索性任务，规划并执行机器人代码策略，验证中间进展，诊断失败，通过密集的步骤级反馈进行重试，并将成功执行提炼为持久的代码技能库。在测试时，智能体从该冻结库中重用相关技能以帮助解决新任务。在LIBERO-PRO和MolmoSpaces上的实验表明，与无探索和随机探索基线相比，通过探索学习的技能提高了保留的下游任务性能，在LIBERO-PRO和MolmoSpaces上分别比CaP-Agent0提高了20.6和17.0个百分点。此外，通过简单地将所学技能检索到上下文中，可以将其插入其他推理时代的代码即策略智能体中，无需微调底层模型即可在RoboSuite和实际世界迁移中分别提高8.9和8.8个百分点。

## Abstract
Current agentic robot systems can write executable Code-as-Policy programs, observe feedback, and revise behavior across multiple attempts, but they remain largely task-driven: reusable skills are acquired only after explicit instructions. We study Playful Agentic Robot Learning, where an embodied coding agent uses self-directed play as a continual skill-learning stage before downstream tasks arrive. We introduce RATs, Robotics Agent Teams designed for play-time skill acquisition. During play, RATs proposes novel yet learnable exploratory tasks, plans and executes robot-code policies, verifies intermediate progress, diagnoses failures, retries with dense, step-level feedback, and distills successful executions into a persistent code skill library. At test time, the agent reuses relevant skills from this frozen library to help solve new tasks. Experiments in LIBERO-PRO and MolmoSpaces show that play-learned skills improve held-out downstream tasks over no-play and random-play baselines, with 20.6 and 17.0 percentage-point gains over CaP-Agent0 on LIBERO-PRO and MolmoSpaces, respectively. Moreover, the learned skills can be plugged into other inference-time Code-as-Policy agents by simply retrieving them into the context, improving RoboSuite and real-world transfer by 8.9 and 8.8 points, respectively, without finetuning the underlying model.

### 论文详细总结：趣味性自主机器人学习

#### 1. 核心问题与整体含义（研究动机和背景）

*   **核心问题**：当前的具身机器人代理系统（尤其是采用代码即策略范式的系统）是**任务驱动**的。它们仅在收到明确的、外部的指令后，才会编写、执行和修正代码以完成任务。这意味着可复用技能的获取是被动且反应式的，机器人不会利用空闲时间主动学习和积累新能力。这与人类的自然学习模式（尤其是儿童通过玩耍来探索和掌握新技能）形成了鲜明对比。
*   **研究动机**：受发展心理学和内在动机研究的启发，本文提出**趣味性自主机器人学习**这一新范式。其核心思想是：让一个具身编码代理能够在没有具体任务指令的情况下，通过**自我导向的玩耍**，作为一个持续的技能学习阶段，主动地、自主地探索环境，练习新交互，并将成功的经验提炼为**可复用的代码技能**。这样，当后续的下游任务到来时，机器人可以利用前期积累的技能库更高效地解决问题。
*   **整体含义**：这项研究旨在将经典的“内在动机”、“好奇心驱动探索”等思想与现代的“代码即策略”代理框架相结合，探索一种更主动、更通用的机器人技能获取方式，使其从“完成任务的工具”向“能够自我提升的学习者”迈进一步。论文强调，通过玩耍学习的技能库可以作为一种**即插即用**的模块，在不微调底层模型的情况下提升现有系统的性能。

#### 2. 提出的方法论：核心思想、关键技术细节

*   **核心思想**：提出**RATs（Robotics Agent Teams）** 系统。RATs将玩耍视为一个明确的、结构化的技能获取过程。它通过多代理协作（多智能体团队），在玩耍阶段自主完成“提议-执行-验证-记忆”的闭环。
*   **关键技术细节**：
    *   **整体流程（算法1）**：RATs在玩耍阶段循环执行 `Propose Task -> Run Task -> Update Memory`。
        *   **Skill Library (L)**：包含初始原语 `L0` 和玩耍阶段学习到的代码技能 `L_learned`。
        *   **Failure Memory (M)**：存储失败尝试的教训，用于指导后续重试。
    *   **任务提议团队**：负责提出要练习的任务。
        1.  **候选任务生成**：基于当前场景、技能库和失败记忆，由大语言模型生成多样化的候选任务。
        2.  **“金发姑娘”任务选择**：通过一个分析评分函数选择任务，该函数平衡了**探索性**和**可学习性**。
            *   **新颖性得分 (Novelty N(τ))**：鼓励探索罕见的“对象-技能”组合。公式为 `1/(|O(τ) x S(τ)|) * sum(1/sqrt(N(o,s)+1))`，其中 `N(o,s)` 是历史尝试次数。
            *   **能力前沿得分 (Competence Frontier F(τ))**：倾向于选择技能的成功率接近50%（`0.5 * sqrt(r * (1-r))`，即 `r(1-r)` 的平方根乘以0.5，文中为 `4 * r * (1-r)` 的平方根，取最大值的一半）的任务，即那些“不太难也不太简单”的处于能力边界上的任务。
    *   **执行团队**：负责执行被选中的任务。
        1.  **规划器**：生成带步骤的计划。
        2.  **策略编写器**：将计划转化为可执行的机器人控制代码。
        3.  **验证代理**：提供多层反馈，包括规划验证（场景合理性）、代码质量检查、失败诊断等。重试时会根据诊断结果提供密集的**步骤级反馈**。
        4.  **循环机制**：执行一个“编写-执行-验证-诊断”的内部循环，在重试预算内尝试修正错误。
    *   **记忆管理团队**：负责维护两个长期存储库。
        1.  **技能库更新**：任务成功时，从成功代码中提取出**自包含、有参数化**的函数作为新技能入库；技能有可靠性等级（实验级、已验证、已弃用）。
        2.  **失败记忆更新**：任务失败时，记录失败的经验并提炼成简洁的教训（例如“某个前提条件缺失”、“应使用哪种修正方法”）。
        3.  **记忆整理**：定期合并类似技能和教训，或根据失败模式主动提议新技能（`Skill Proposer`）。
    *   **测试阶段**：冻结技能库，禁用任务提议和记忆更新。技能库可以有两种使用方式：
        1.  **即插即用**：直接作为API上下文注入到标准CaP代理（如CaP-Agent0）中。
        2.  **RATs执行**：使用完整的RATs执行系统（规划器、验证器、重试循环等）配合技能库来完成任务。

2.  **方法可解释且模块化**：RATs的多代理团队结构清晰，每个组件（提议、规划、编写、验证）的功能和交互明确，使得系统的决策过程可追踪、可调试。学习到的技能是显式的代码，易于理解和迁移。
3.  **实验设计扎实**：从多个维度（领域内、跨环境、真实世界）进行了评估，并通过消融实验清晰地证明了每个关键组件（好奇提议、完整执行系统）的贡献，结论可靠。
4.  **实用性强**：展示了将学到的技能库作为“即插即用”插件的能力，这降低了在不同机器人系统间共享和应用学习成果的门槛。
5.  **关注学习效率**：通过token成本分析，证明了将计算资源投入到前期的“玩耍”学习中，比单纯在后续任务中增加推理重试次数要更高效。

#### 8. 不足与局限

1.  **模拟依赖性强**：主要评估集中在模拟环境。真实世界实验规模非常有限（仅两个任务，40次试验），不足以证明其在复杂、动态物理场景下的鲁棒性。
2.  **技能库局限性**：
    *   能学习的技能范围受限于模拟环境的多样性（对象、物理规则、场景布局）。
    *   初次使用不当（或与其上下文不符）的技能可能会导致性能下降 (有些技能的Reuse并没有带来提升，例如在两臂任务上的-4%)。这强调了需要更好的上下文感知和检索机制。
    *   学习到的技能是代码层面的，受限于底层控制API的精细程度（例如无法学习精细的灵巧操作）。
3.  **计算成本高**：RATs严重依赖大型语言模型和视觉语言模型，无论是在玩耍阶段（提议、规划、诊断、提炼）还是测试阶段（规划、验证），其推理计算成本（Token消耗）较高。论文中的Token成本分析也印证了这一点，尤其是失败诊断消耗了最多资源。
4.  **验证代理的依赖性**：系统的成功率高度依赖于验证代理（特别是视觉验证）的准确性。如果验证器经常出错或产生幻觉，会误导诊断和重试过程，降低学习效率。
5.  **规模化问题**：系统处理的是“家庭和操作”类的任务，未探索到更复杂或需要长时间规划的任务。随着技能库和记忆库的增长，检索和整理的效率可能成为瓶颈。
