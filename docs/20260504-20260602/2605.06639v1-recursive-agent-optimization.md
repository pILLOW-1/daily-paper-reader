## 摘要
我们引入了递归智能体优化（RAO），这是一种用于训练递归智能体的强化学习方法：递归智能体能递归地生成子任务并委派给自身的新实例。递归智能体实现了一种推理时缩放算法，通过分治策略自然允许智能体扩展到更长的上下文并泛化到更困难的问题。RAO提供了一种训练模型以最佳利用这种递归推理的方法，教会智能体何时以及如何委派和通信。我们发现以这种方式训练的递归智能体具有更好的训练效率，可以扩展到超出模型上下文窗口的任务，泛化到比训练时困难得多的任务，并且与单智能体系统相比可以减少实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

# Recursive Agent Optimization (RAO) 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **当前问题**：大语言模型（LLM）智能体在解决真实世界任务时，面临长时域、大有效工作记忆、大量探索与回溯等挑战。许多任务天然适合“分而治之”，但现有递归/多智能体系统**仅将递归作为推理时的固定脚手架**，模型本身并未学习何时委派、如何制定子任务、如何跨层级通信以及如何合成子智能体输出。
- **研究目标**：训练模型以有效利用递归推理，使其具备自主分治、自适应分配计算资源的能力，从而扩展到更长上下文、更困难的任务，并提升训练效率。
- **整体意义**：提出一种强化学习（RL）框架，端到端地训练递归智能体，让模型学会“何时委派、委派什么、如何委派、如何聚合结果”，同时利用递归结构产生自然的课程学习信号，提升泛化能力和推理时扩展性。

## 2. 方法论：核心思想、关键技术、公式与算法流程

### 2.1 核心思想
- **递归智能体**：在推理时，智能体可以动态生成执行树，每个节点代表一个策略实例（共享参数）。根节点处理原始任务，子节点处理委派的子任务，子任务可进一步递归。
- **训练目标**：使用强化学习优化所有节点（根、内部、叶子）上的策略，使模型学会**正确解决当前任务**以及**有效委派子任务**。

### 2.2 关键技术细节
- **委派原语**：通过异步函数 `async launch_subagent(goal, ...)` 实现。支持顺序与并行（`asyncio.gather`）委派。
- **局部节点奖励（公式(1)）**：
  \[
  R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \frac{1}{|C(X)|} \sum_{c \in C(X)} \tilde{s}(c, \tau_c)
  \]
  其中 \(\tilde{s}\) 为节点成功信号（可由环境验证器、LLM评审判定或根节点奖励代理），第二项为**委派奖励**（鼓励产生高质量子任务）。
- **优势估计（公式(3)）**：利用 leave-one-out 基线，以同一批次内其他根节点奖励的平均作为基线，保证无偏。
- **深度级逆频率加权（公式(4)(5)）**：避免深层轨迹过多导致优化失衡，对每层轨迹赋予权重 \(w_d = \alpha \cdot 1/N_d\)。
- **共享策略**：所有节点使用同一个策略网络（同一个LLM），训练时联合优化所有深度上的任务分布。

### 2.3 算法流程概要
1. 对于每个根任务，采样 G 个独立递归执行树。
2. 每个节点根据当前策略生成动作（包括委派子任务、执行工具调用、完成任务等）。
3. 计算每个节点的局部奖励。
4. 对每个轨迹，计算优势（使用 leave-one-out 根奖励基线）。
5. 按深度计算权重，加权计算策略梯度，更新模型参数。
