## 摘要
自演化多智能体系统（MAS）已成为LLM智能体通过持续经验改进的有前途的途径，其基础在于持久记忆。然而，现有设计几乎完全采用跨智能体共享的集中式存储库，导致通信和协调开销，引发隐私问题，并削弱智能体多样性。我们提出DecentMem，一种去中心化记忆框架，其中每个智能体维护自己的双池记忆——一个由历史轨迹整合而成的利用池和一个由LLM生成的用于未见情境的候选探索池。两个池基于来自LLM作为评判者的阶段性反馈在线重新加权。理论上，我们证明该设计保证了解决方案空间的全局可达性，并实现了$O(\log T)$的累积遗憾，与随机赌博机下界在常数级别上匹配。在实践中，跨越三个MAS框架（AutoGen、DyLAN、AgentNet）、三个Qwen3骨干模型（4B/8B/14B）、两个Gemma4骨干模型（E2B/E4B）以及涵盖数学、代码、问答和具身任务的五个基准测试，DecentMem相较于最强集中式记忆基线平均准确率提升高达23.8%，相较于无记忆基线提升高达52.5%，同时令牌使用量减少高达49%。

## Abstract
Self-evolving multi-agent systems (MAS) have emerged as a promising route to LLM agents that continually improve from experience, with persistent memory at their foundation. However, existing designs almost exclusively adopt a centralized repository shared across agents, incurring communication and coordination overhead, raising privacy concerns, and collapsing agent diversity. We propose DecentMem, a decentralized memory framework in which each agent maintains its own dual-pool memory -- an exploitation pool of consolidated past trajectories and an exploration pool of LLM-generated candidates for unseen contexts. The two pools are reweighted online based on stage-wise feedback from an LLM-as-a-judge. Theoretically, we prove that this design guarantees global reachability of the solution space and achieves $O(\log T)$ cumulative regret, matching the stochastic bandit lower bound up to constants. In practice, across three MAS frameworks (AutoGen, DyLAN, AgentNet), three Qwen3 backbones (4B/8B/14B), two Gemma4 backbones (E2B/E4B) and five benchmarks spanning math, code, QA, and embodied tasks, DecentMem improves average accuracy by up to 23.8% over the strongest centralized memory baseline and by up to 52.5% over the no-memory baseline, while reducing token usage by up to 49%.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有自演化多智能体系统（MAS）普遍采用**中心化记忆**架构——所有智能体共享同一个记忆池。这种设计导致三大弊端：  
  - **通信与协调开销**：智能体频繁读写共享池，带来同步和一致性负担。  
  - **隐私风险**：所有经验集中存储，暴露给所有智能体。  
  - **智能体多样性丧失**：共享记忆迫使所有智能体学习相同策略，削弱角色互补性，使协作失去意义。  

- **研究动机**：在多智能体场景中，自演化应保留并强化智能体间的专业化分工，而非趋向单一策略。因此需要一种**去中心化**的记忆机制，让每个智能体维护私有经验，并自主平衡“利用”和“探索”。  

- **整体含义**：本文提出 DecentMem，首个为 LLM 多智能体系统设计的去中心化记忆框架，在理论（全局可达性、对数遗憾界）和实证（多个框架、模型、基准）上均证明其优于中心化方案，且能保持智能体多样性、降低 token 消耗。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：为每个智能体构建私有的**双池记忆**结构：  
  - **利用池（E-pool）**：存储从过去任务中整合的成功轨迹（包括协作轨迹和自评注释），用于检索相似历史经验。  
  - **探索池（X-pool）**：由 LLM 为未见上下文生成的候选记忆片段，用于注入新策略，避免陷入局部最优。  

- **在线路由机制**：  
  - 每个智能体在每阶段根据当前权重 \(w_{\text{E-pool}}\) 和 \(w_{\text{X-pool}}\) 以概率 \(\alpha = w_{\text{E}}/(w_{\text{E}}+w_{\text{X}})\) 选择 E-pool 或 X-pool。  
  - 若选 E-pool，执行相似度检索（Top-K，阈值 τ）；若无匹配则回退至 X-pool。  
  - 使用 LLM-as-a-judge 对每阶段结果进行阶段级评分（正确性、分配质量、中间连贯性、最终融合）。  
  - 根据评分变化 \(\Delta_t\) 更新路由权重：  
    - 若使用 E-pool 且评分提高 → 增加 \(w_{\text{E}}\)；评分下降 → 衰减 \(w_{\text{E}}\)。  
    - 若使用 X-pool 且评分提高 → 衰减 \(w_{\text{E}}\)（鼓励持续探索）；评分下降 → 增加 \(w_{\text{E}}\)。  
    - 固定 \(w_{\text{X}}=1\)。  

- **记忆合并**：任务完成后，X-pool 的所有候选记忆整合到 E-pool 中，X-pool 清空。  

- **理论保证**：  
  - 将每个智能体的搜索建模为带启发式传送的图随机游走（E-pool 为局部转移矩阵 \(T_m\)，X-pool 为 LLM 先验 \(h_m\)），证明当 \(\alpha <1\) 且 \(h_m\) 全支撑时，转移矩阵严格正，马尔可夫链不可约且非周期，实现**全局可达性**。  
  - 将在线路由建模为随机赌博机问题，证明在严格凹假设下，累积遗憾为 \(O(\log T)\)，匹配下界 \(\Omega(\log T)\)，达到阶最优。

### 6. 论文的主要结论与发现

1. **性能优势**：DecentMem 在 15 个（骨干, 框架）组合的 14 个中取得最佳平均准确率，相对最强集中式基线 G-Memory 平均提升 **8.6%**，相对无记忆基线平均提升 **26.1%**（最高 52.5%）。  
2. **去中心化收益随协作随机性增加而扩大**：从 AutoGen → DyLAN → AgentNet，准确率提升幅度从 ~2.7% 增至 ~23.1%（Qwen3）和 ~1.7% 增至 ~6.8%（Gemma4），表明在随机协作条件下，集中式记忆更容易吞噬智能体多样性。  
3. **token 消耗显著降低**：相比 G-Memory，在 BBH 任务上 token 使用减少 **32%~49%**（平均 43%），同时准确率更高。  
4. **自演化更快**：DecentMem 在较少任务数内即可达到或超越集中式基线的最终准确率，尤其在 DyLAN 上收敛速度约快 2.5 倍。  
5. **在线路由关键**：消融实验表明，移除在线更新（使用固定权重 α=0.5）会导致性能下降约 3.5~7%，而纯探索或纯利用策略均不优。
