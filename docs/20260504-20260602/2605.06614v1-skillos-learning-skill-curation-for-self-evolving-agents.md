## 摘要
基于大语言模型的智能体正越来越多地用于处理流式任务，但它们往往仍然是无法从过往交互中学习的一次性问题解决者。从经验中提炼出的可复用技能为自我进化提供了天然基础，其中高质量的技能策展成为关键瓶颈。现有方法要么依赖手动技能策展，要么预设启发式技能操作，要么训练短视技能操作。然而，它们仍难以从间接且延迟的反馈中学习复杂的长期策展策略。为应对这一挑战，我们提出SkillOS，一种经验驱动的强化学习训练方案，用于在自我进化智能体中学习技能策展。SkillOS将冻结的智能体执行器（用于检索和应用技能）与可训练的技能策展器（用于从累积经验中更新外部技能存储库）配对。为提供策展的学习信号，我们设计了复合奖励，并基于技能相关任务依赖在分组任务流上进行训练，其中早期轨迹更新技能库，后续相关任务评估这些更新。在多轮智能体任务和单轮推理任务中，SkillOS在效果和效率上均一致优于无记忆和强记忆基线，且学到的技能策展器能跨不同执行器主干和任务领域泛化。进一步分析表明，学到的策展器能产生更具针对性的技能使用，而技能库中的技能随时间演变为结构更丰富的Markdown文件，编码了更高级的元技能。

## Abstract
LLM-based agents are increasingly deployed to handle streaming tasks, yet they often remain one-off problem solvers that fail to learn from past interactions. Reusable skills distilled from experience provide a natural substrate for self-evolution, where high-quality skill curation serves as the key bottleneck. Existing approaches either rely on manual skill curation, prescribe heuristic skill operations, or train for short-horizon skill operations. However, they still struggle to learn complex long-term curation policies from indirect and delayed feedback. To tackle this challenge, we propose SkillOS, an experience-driven RL training recipe for learning skill curation in self-evolving agents. SkillOS pairs a frozen agent executor that retrieves and applies skills with a trainable skill curator that updates an external SkillRepo from accumulated experience. To provide learning signals for curation, we design composite rewards and train on grouped task streams based on skill-relevant task dependencies, where earlier trajectories update the SkillRepo, and later related tasks evaluate these updates. Across multi-turn agentic tasks and single-turn reasoning tasks, SkillOS consistently outperforms memory-free and strong memory-based baselines in both effectiveness and efficiency, with the learned skill curator generalizing across different executor backbones and task domains. Further analyses show that the learned curator produces more targeted skill use, while the skills in SkillRepo evolve into more richly structured Markdown files that encode higher-level meta-skills over time.

- **研究动机**：基于LLM的智能体在流式任务中往往是一次性问题解决者，无法从过去的交互中学习并积累经验。为了实现自我进化（self-evolution），需要将经验提炼为可复用的技能（skills），而高质量技能策展（curation）是关键瓶颈。
- **现有局限**：当前方法要么依赖人工策展（无法扩展），要么使用启发式规则（缺乏下游反馈），要么只进行短视的技能操作训练（无法学习复杂的长期策展策略）。反馈是间接且延迟的，技能策展决策对后续任务的影响需要通过执行器的性能来体现。
- **整体含义**：SkillOS提出一种经验驱动的RL训练方法，使智能体能够学习如何从经验中策展技能，从而在长期任务流中自我进化，提升性能和效率。

## 2. 方法论

### 核心思想
- 采用模块化多智能体框架：冻结的**Agent Executor**（智能体执行器）负责使用技能解决当前任务；可训练的**Skill Curator**（技能策展器）负责通过函数调用（insert/update/delete）更新外部**SkillRepo**（技能库）。
- 技能表示为Markdown文件（含YAML元数据和Markdown指令），类似操作系统文件管理。
- 训练时构造**任务组**（grouped task streams），组内任务具有技能相关性：早期任务的经验更新技能库，后续任务评估这些更新的效果，从而将延迟反馈转化为学习信号。

### 关键技术细节
1. **任务分组**：使用Gemini-2.5-Pro为每个任务标注属性（主题、技能、概念、策略、常见陷阱），基于属性相似度将任务聚集成组。
2. **复合奖励函数**：
   - 任务结果奖励（\( r_{task} \)）：除第一个任务外，后续任务的平均成功率。
   - 函数调用格式奖励（\( r_{fc} \)）：有效函数调用的比例。
   - 内容质量奖励（\( r_{cnt} \)）：使用外部评估器（Qwen3-32B）对技能内容进行评分，评估抽象性、复用性、可操作性、忠实性。
   - 压缩奖励（\( r_{comp} \)）：鼓励技能库紧凑，避免直接复制完整轨迹。
   - 总奖励：\( r = r_{task} + \lambda_f r_{fc} + \lambda_u r_{cnt} + \lambda_c r_{comp} \)
3. **策略优化**：使用GRPO（Group Relative Policy Optimization），每个训练步骤采样8个独立rollout，计算优势并更新策展器策略。

### 算法流程（文字描述）
1. 对每一个训练步骤，采样一个任务组，初始化空SkillRepo。
2. 遍历任务组中的每个任务：
   - 从SkillRepo使用BM25检索相关技能。
   - 冻结的执行器基于检索到的技能执行任务，产生轨迹。
   - 策展器基于轨迹和当前技能库生成一系列策展操作（插入/更新/删除），并更新SkillRepo。
3. 计算所有任务的复合奖励。
4. 使用GRPO更新策展器策略（Qwen3-8B）。

## 7. 优点

- **模块化设计**：冻结执行器、独立训练策展器，便于替换执行器或任务域，降低训练成本。
- **长时程学习**：通过任务分组将长跨度反馈转化为学习信号，克服了短视训练局限。
- **复合奖励**：结合任务结果、函数格式、内容质量、压缩，引导策展器生成高质量且紧凑的技能。
- **低参数策展器超越大模型**：8B模型经过RL训练后，策展策略优于直接使用Gemini-2.5-Pro，证明了训练的价值。
- **技能表示灵活**：采用标准Markdown格式，易于人读和后续扩展。
- **分析深入**：对策略行为、技能结构演化、技能使用归因进行了量化分析，揭示模型学习机理。
