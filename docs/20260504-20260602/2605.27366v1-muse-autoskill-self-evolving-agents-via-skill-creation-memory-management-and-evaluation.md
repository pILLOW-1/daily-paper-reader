## 摘要
大型语言模型（LLM）智能体依赖可重复使用的技能来解决复杂任务。然而，现有的技能创建方法将技能视为孤立和静态的工件，限制了它们的可重用性、可靠性和长期改进。我们提出MUSE-Autoskill智能体（利用记忆的技能进化），这是一个以技能为中心的智能体框架，允许智能体通过在一个统一的生命周期（创建、记忆、管理、评估和优化）中创建、重用和改进技能，持续提升其任务解决能力。我们的框架使智能体能够按需创建技能，跨任务存储和重用技能，高效组织和选择技能，并通过单元测试和运行时反馈对技能进行评估以进行持续优化。我们进一步引入了技能级记忆，该记忆会为每个技能积累跨任务的经验，从而随着时间的推移实现更有效的重用和适应。在SkillsBench上的实验提供了初步证据，表明经生命周期管理的技能可以提高任务成功率、效率、重用性以及跨智能体迁移能力，强调了将技能视为长期存在、具有经验意识且可测试的资产的重要性。

## Abstract
Large language model (LLM) agents rely on reusable skills to solve complex tasks. However, existing skill creation approaches treat skills as isolated and static artifacts, limiting their reusability, reliability, and long-term improvement. We propose MUSE-Autoskill Agent (Memory-Utilizing Skill Evolution), a skill-centric agent framework that lets agents continuously improve their task-solving capability by creating, reusing, and refining skills under a unified lifecycle (creation, memory, management, evaluation, and refinement). Our framework enables agents to create skills on demand, store and reuse them across tasks, organize and select them efficiently, and evaluate them through unit tests and runtime feedback for continuous refinement. We further introduce skill-level memory that accumulates experience for each skill across tasks, enabling more effective reuse and adaptation over time. Experiments on SkillsBench provide initial evidence that lifecycle-managed skills can improve task success, efficiency, reuse, and cross-agent transfer, highlighting the importance of treating skills as long-lived, experience-aware, and testable assets.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：现有的 LLM 智能体技能创建方法（如 Voyager、AutoSkill、SkillGen 等）将技能视为孤立的、静态的一次性生成产物，缺乏系统化的生命周期管理。这导致技能的可重用性、可靠性和长期改进能力受限，无法在跨任务、跨会话甚至跨智能体场景中有效积累和演化。
- **背景**：技能是 LLM 智能体实现复杂任务的核心抽象，但当前方法存在四大缺口：① 创建与使用脱节（技能生成时未接入运行时的上下文）；② 缺乏针对每个技能的结构化跨任务经验记忆；③ 技能未经单元测试验证，无法自动评估和细化；④ 上下文管理粗糙（扁平对话历史易截断或溢出）。因此，需要将技能视为**长期存在、具有经验意识、可测试的资产**，并纳入统一生命周期管理。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：提出 MUSE-Autoskill 框架，构建**技能的统一生命周期**（创建 → 记忆 → 管理 → 评估 → 细化），使智能体能够动态创建、存储、复用、测试和持续改进技能，实现自我进化。
- **关键技术细节**：
  - **技能结构**：每个技能为一个结构化目录，包含 `SKILL.md`（接口定义）、`scripts/`（可执行代码）、`tests/`（单元测试）、`resources/`（辅助数据）。遵循 Anthropic Agent Skills 格式，保证可移植性。
  - **创建阶段**：通过内置工具 `skill_create` 在运行时循环内动态生成技能。生成后立即运行 `tests/` 中的单元测试，仅测试通过的技能才注册到技能库。
  - **记忆系统**：
    - **技能级记忆**：每个技能附带 `.memory.md` 文件，跨任务累积经验（如常见失败模式、输入格式细节），下次调用时自动调取。
    - **短时记忆**：维护当前任务上下文，自适应压缩（Level-1 单节点摘要、Level-2 连续节点合并）。
    - **长时记忆**：跨会话持久化笔记（如环境偏好、通用经验），不受压缩影响。
  - **上下文管理**：采用 DAG 结构存储对话节点，每个节点记录计划-动作-观察三元组。自适应压缩算法在 token 超预算时先做节点级摘要，仍超则合并中间节点，保留首尾固定轮次（各 5 轮）原样。原始节点始终保留，可回溯。
  - **评估与细化**：单元测试驱动筛选，失败时触发 `update_skill` 修补后再注册。支持技能合并、淘汰等管理操作。
  - **跨智能体转移**：技能以纯文本形式存在，无需修改即可供不同智能体直接使用。

- **未涉及多种骨干模型验证**：所有实验仅使用 GPT-5.5，其他模型（如开源模型）上的表现未知。
